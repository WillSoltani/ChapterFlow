## 3. Evaluation architecture (the one hierarchy)

1. **Full-book release standard** — the evaluator skill, unmodified: dual mutually-blind raters + fresh adjudicator + dispatch receipts + pair seal + `validate_book_result.py --require-full-content`, all chapters read in full, 9 domains/36 subcriteria/5 gates, deterministic arithmetic. The pipeline gains an *adapter* (`src/evaluation/`), never a reimplementation. If Codex workers cannot be dispatched, the step stops as `BLOCKED_NO_CODEX_RATER` with pending job manifests — never a Claude substitute.
2. **Chapter-screening diagnostic** — a genuine **1-chapter package** evaluated full-content (chapter *sampling* stays hard-failed, `validate_book_result.py:518-519`; the structured 1-chapter **JSON** package path is proven by WP-E11's tests, which run the skill's real `inspect_package.py` on a built package and get `chapter_count: 1` + `inventory_complete: true` — not inferred from the single-`.md` fallback at `common.py:515-531`). Output uses the existing `chapterflow_standalone_chapter_adjudication` 1.0.0 artifact family (PM-4..6 precedent — no third format): `scope_type: standalone_chapter_audit`, `full_book_score: null`, certification unevaluable, Domain 9 unassessable. Anti-masquerade (WP-E13): `chapterdiag--` book-id prefix; artifacts under `state/model-bakeoffs/<bookId>/chapter-diagnostics/` (never `artifacts/chapterflow-evaluation/`); wrapper manifest `not_a_book_score: true`; portfolio scripts (`aggregate_results.py`, `export_portfolio_book_update.py`, `update_portfolio_report.py`, `render_report.py`) never invoked on diagnostics.
3. **D7 operational reviewer** — GPT-5.6 Sol @ ultra via `ultraSession` (codex envelope; §4). Secondary by construction: may trigger inspection/downgrade, never select, never override a source-bound evaluator result. Because Sol judges Sol-authored candidates, the judge-interaction analysis (§5.6) is mandatory; disqualifying patterns demote D7 to descriptive.
4. **Content anchors** (WP-E51) — read-only study of 2–3 high-scoring books with different nonfiction types (difficult-conversations 90.1 communication `prior`; the-willpower-instinct 89.7 science-explainer `prior`; peak 87.9 skill-building `deep_practical`; all packages verified present in `book-packages/`), contrasted with one low scorer where useful. ### 5.2 Instruments, anchors, band
- **E-audit** (PRIMARY): adjudicated standalone chapter diagnostic via the evaluator adapter = 3 codex sessions (2 raters + adjudicator) per cell. Primary metric = renormalized 8-domain chapter score (Σ weighted points for domains 1–8, ÷0.95); Domain 9 unevaluable, never imputed; the renormalization is order-preserving and the band is defined on the same scale. **Rater route pinned and recorded** (red-team F1): E-audit raters/adjudicators run the same `resolveD7RaterRoute()` Sol-ultra envelope as D7 — the rater model is never an ambient codex default; every session's resolved model is receipted, and the uniformity rule below applies.
- **D7-lite** (SECONDARY): single-rater Sol-ultra rubric-audit session per replicate-1 cell; signs/patterns only. Calibration (red-team F2): the three legacy mid-band anchors (70.757 nudge-ch03 / 68.816 happiness-ch06 / 67.664 made-to-stick-ch04, tolerance 3.0) do NOT bracket the 75 threshold rule 7 uses, so the Stage-0b drill adds **≥1 high-band anchor from the sealed `docs/v25/rubric-audit-2026-07-15` owner-adjudicated reference set (~90 band)**; if no high-band anchor is available or the drill fails there, **rule 7's 75 gate is dropped as uncalibrated** and D7 becomes descriptive-only.
- **Anchors for E** (from the 8 `prior`-profile close-read books, excluding corpus books): A_high = `difficult-conversations` (book score 90.1 — the book score only SELECTS the book), A_mid = `multipliers` (72.3, same caveat); chapter pick deterministic (⌈n/2⌉ of inventory). 2 repeat E-audits each → pooled test-retest SD.
- **Equivalence band:** `W = max(2 × SD_retest, 2.0)`, frozen after Stage 0b; if `2×SD_retest > 4.0` → **noise STOP** (instrument work, never band inflation — the band is never set above 4.0 because the STOP fires first). The old ±3.0 was a property of the retired instrument and is not carried over.
- **Floors (formulas now, constants after 0b; red-team F7):** `mean(A_high)` means the pooled **chapter-diagnostic re-score** of the A_high anchor chapter from Stage 0b — NEVER the 90.1 full-book score (using the book score would set a floor of 82.1 that no known chapter clears and would compare a book construct to chapter diagnostics). Screening advance floor = `mean(A_high) − 8`; block floor = `mean(A_high) − 18`; sanity stop if `mean(A_high)` < 75 or > 95. Optional owner hand-adjudication of the 2 anchor chapters = truth check (`|E − owner| ≤ W`); if declined, anchors provide location+noise only (disclosed).

### 5.6 Judge-interaction analysis
**(a) D7 Sol judging Sol (measurable):** per challenger X and block b, compare δ_E = Δ_E/W vs δ_D7 = Δ_D7/3.0 (note, red-team #15: the two δ are in **per-instrument noise units**, so P2's 1.0 trip point scales with the frozen W/3.0 ratio — sensitivity is stated with the frozen W). Disqualifying patterns (any → D7 demoted to descriptive, disclosed): **P1** sign flip (sign(Δ_D7) ≠ sign(Δ_E) in ≥2/3 blocks while |mean Δ_E| > W); **P2** uniform self-inflation (mean(δ_E − δ_D7) > 1.0 Sol-favoring); **P3** calibration miss (any drill anchor — mid-band OR high-band — or any drift unit |Δ| > 3.0). One-sided by design: pro-Sol D7 bias pushes toward the expensive incumbent — the direction the cost policy most needs protected.
**(b) Evaluator rater — pinned Sol-ultra, same family as candidate Sol (red-team F1):** the primary instrument's raters are PINNED to `resolveD7RaterRoute()` (never an ambient default) and every session's resolved model is receipted; the **uniformity rule** (all Stage-1/2 sessions one rater model, else stratify + halt) guards drift. Family-level bias is common-mode and largely differences out of the paired Δs; the residual exact-model kinship (Sol rating Sol-authored cells) cannot be measured by a second in-house instrument (D7 shares the same family), so the primary instrument gets these pre-registered protections: (i) the **owner blind Stage-2 read is REQUIRED**, not optional — recorded before unblinding; (ii) if the owner's blind ranking of the Stage-2 cells disagrees in SIGN with the E-ranking on the Sol-vs-winner comparison, the verdict is **INCONCLUSIVE-pending** (owner decides with the disagreement on the table); (iii) the kinship limitation is stated verbatim in every report: under the no-Claude policy no cross-family machine judge exists — this is the single largest validity concession of the policy.

### 5.7 Analysis and decision rule
Unit = adjudicated E per (model, block, replicate); blind pair scores are adjudication inputs, never pooled. Per-block paired Δ vs Sol; across-block mean; within-model spread; worst cell; gate rates; failures stay in the denominator. A clustered bootstrap (blocks, then replicates) is reported **as indicative dispersion only** (red-team F5: 3 clusters cannot support a stable CI) — **no decision rule keys on a CI**; decisions key on sign-consistency across blocks, the worst cell, the ±W band on mean Δ, and Stage-2 replication. Sensitivity recompute excluding chapter-strained subcriteria (3.3, 4.1, 5.2) — winner's sign must hold, else INCONCLUSIVE. Decision (in order, after Stage 2): **(0)** validity preconditions else INCONCLUSIVE; **(1)** ineligibility on adjudicator-confirmed candidate-attributable gate-2/3 failure in ≥2 cells (D7 alone never disqualifies — it triggers inspection); **(2)** superiority: > W above runner-up, signs consistent → provisional default + pilot candidate (quality wins with or without price data); **(3)** within ±W → cheaper wins **only with** a versioned price table, else quality tie → owner; **(4)** below −W cannot be price-rescued; **(5)** no dominance → Pareto frontier → owner; **(6)** nobody clears → Sol stays, STOP, bar unmoved; **(7)** D7 safety check (if it survived §5.6): winner below D7 75 on ≥2 blocks → INCONCLUSIVE-pending owner blind read (downgrade-only); **(8)** INCONCLUSIVE is a legal terminal outcome; **(9)** owner blind preference recorded pre-unblinding, usable only in rules 3/5 + pilot sign-off. Unblinding cannot change the frozen analysis.
