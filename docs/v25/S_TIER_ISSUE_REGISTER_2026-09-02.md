# V25 issue register (2026-09-02)

265 issues from a nine-surface discovery sweep (Opus finders, Opus adversarial refuters) merged with the Phase A report. Severity: {'critical': 48, 'major': 161, 'minor': 56}. Verification: {'CONFIRMED': 177, 'PARTIAL': 28, 'UNVERIFIED': 60}. Machine-readable copy: `S_TIER_ISSUE_REGISTER_2026-09-02.json`. Waves are defined in `S_TIER_EXECUTION_PLAN_2026-09-02.md`; not every issue will be fixed in the current campaign — the plan names what is in scope, and the rest stays here as the backlog.

## Themes

- ACCURACY IS BORN AT RESEARCH, AND NOTHING EVER CHECKS IT. The pipeline never reads the book. The researcher writes a sidecar from memory, that sidecar is saved into a folder called 'source-freeze', and from then on every gate that says 'grounded in source' means only 'consistent with what the model recalled'. The Franklin revision-6 sidecars already contain the errors the book shipped — the inverted Penn meeting, the fire company with no dues fund, the invented unresolved ending — so no downstream fix could ever have caught them. The one apparatus that could compare a fact to a real text exists in full (a workbench, six CLI verbs, a checker, a rubber-stamp detector) and is switched off by a single line that contradicts its own file header. The Autobiography is public domain and free; ingesting it and quote-matching the sidecar against it is the cheapest accuracy win available anywhere in this system. Until that lands, every accuracy gate downstream is theatre, and the eight verified distortions will keep being reproduced faithfully.

- THE PROMPT TELLS THE WRITER THINGS THAT ARE NOT TRUE. Four contract lines end 'the validator enforces this' about dealt fields no gate reads. The retry card states a matching rule the gate abandoned months ago, and then tells the writer to open a sentence with the raw research token — which is precisely the seam readers named ('until a speckled Ax is best won out'). One blocker message names a tier its own haystack excludes, so the cheapest repair is to copy fullRead sentences up into deepRead, which is the restatement defect a different check flags. Seventy-six of the eighty-two phrases that fail the draft are never shown to the writer. The live delivery branch silently drops the paragraph that tells the writer a gate exists at all. A writer who discovers that some enforcement claims are false discounts all of them, true ones included — so these are not cosmetic; they are the reason the writer trusts the wrong constraints.

- VERBATIM-TOKEN QUOTAS MANUFACTURE BOTH THE SEAMS AND THE SAMENESS. Research is required to emit short 'hard specifics' with a five-word cap, which deletes the relation between them — 'one Dutch dollar' and 'three puffy rolls' arrive as two loose tokens. Six separate gates then demand those tokens verbatim in the tiers, the memorable line, the examples, the quiz prompt AND its explanation, and the cards. The memorable-line rule is the worst case: two mandated proper-noun tokens inside a fourteen-word aphorism leaves no room for a principle, so what ships is a token pair, not a maxim. The quiz version is worse still, because the case is dealt by position rather than relevance, so an unrelated case gets welded into the stem and the explanation then argues against it. One specific ends up hammered eleven to seventeen times per chapter. The fix is not to loosen grounding but to move it: ground once per chapter instead of once per unit, drop the memorable-line quota to one, and deal cases by fact rather than by slot number.

- NOBODY GAVE THE BOOK A VOICE, AND FOUR RULES FORBID ONE. The voice card is hardcoded null on the live route, so every writer prompt for every v25 book carried no register instruction. Meanwhile the research stage already computed Franklin's register — plainspoken, letters to his son, 'errata', dry self-aware irony — wrote it to disk, and shipped it into the same prompt as an unlabelled untrusted record the contract tells the writer to ignore. Four separate lines then hardcode a house register ('short sentences, plain verbs'), including one that fires only when a voice card exists, so it contradicts the card in the same breath. The word budget on the card breaks rather than skips on overflow, silently dropping the plainness floor that was appended last. And the research prompt's own rule against naming the author as an actor erased the protagonist from a memoir: chapter three contains the word 'Franklin' zero times. Wiring the card is one line; making it safe means fixing the four register mandates and the memoirist template in the same change.

- THE GATES MEASURE BOOKKEEPING, NOT LEARNING — AND A REPAIR ROUND VOIDS THEM. More than half the section gate checks citation hygiene: does the id exist, does it resolve, do N of its literal strings appear. None of that is orthogonal to truth; it is unrelated to it. A key that inverts the historical order passes all of it. The pedagogy checks are similarly nominal: a question counts as 'transfer' because the writer typed a metadata label, the distractor-tell budget permits exactly the twenty-two percent rate the rubric it quotes forbids, and the clean-memorable-line check counts candidates in the harvest pool rather than the three lines that ship. Several checks are structurally dead — one can never be true, one is pre-empted by a boilerplate fallback, seven cannot fire on a four-chapter book at all. Worst, the whole gate runs once at assembly; repair lanes then rewrite the same fields with none of the writer's contract and nothing re-gates, which is how a thirty-word line the selector scores at zero ended up in the shipped package.

- NOTHING LOOKS AT THE WHOLE CHAPTER OR THE WHOLE BOOK. Four packs are drafted independently from four narrow slices, and the writer is not even told the chapter title, the book title or the author. Research is per-chapter and context-free, so the same organizing template and the same figure recur by default and are only detected after every chapter is paid for. Intra-chapter tier overlap is collected at the cheap point and thrown away one line before it would be computed; the same measurement exists at the expensive point, fired at forty-five and fifty-eight percent on this very book, and is pinned to advisory so it changed nothing. There is no editor. There is no book-level promotion gate — the blind panel is a per-chapter defect detector whose score axis has never decided anything, and the same rubric read by a different reader class moves twelve points on identical bytes. Waves 2 and 4 exist for this: a whole-chapter editor pass with re-gating, and a book-level rubric gate with a pinned reader model, so before-and-after claims mean something.

- SEQUENCING AND THE ONE HARD CONSTRAINT. Wave 0 is safe: truth-in-contract edits, dead-code repairs, severity mapping, and the quota misclassification that burned nineteen operator rounds in ten minutes. But almost every wave-0 and wave-1 prompt fix ADDS text to a card whose length pins are measured on a fixture with no scars and no voice card — the real Franklin card is roughly double what the test believes it bounds, and the scar file's own history records a production overflow the suite could not see. So the first task in wave 0 is a length test that renders the largest real scar file with a real voice card; everything else in waves 0-1 is budgeted against that number. Wave 1 changes design (source ingestion, per-chapter grounding, fact-aware case dealing); wave 2 adds the two things that do not exist (a fidelity judge and an editor); wave 3 is Franklin's own content; wave 4 is one live --regen run, scored by the same reader class on both sides. Nothing in waves 1-4 should start before the quota classification fix, or the weekly cap will end the run instead of the run ending.
