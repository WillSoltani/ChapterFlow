# Quality Memory

- No chapter starts writer work before brief, outline, quiz blueprint, and source sidecars exist.
- Critic gate must pass before conversion.
- Prose audit runs on edited prose and structured output.
- Tone objects are mandatory for scenarios, whatToDo, and whyItMatters.
- Medium and hard must do different work; hard cannot be longer-medium.
- Review wrapper must contain the full validated chapter JSON inside a one-chapter wrapper.
- Validate shape, contamination, tone separation, quiz presence, and package-wide repetition before sealing.
- Seal continuity hash only after chapter gate passes.
