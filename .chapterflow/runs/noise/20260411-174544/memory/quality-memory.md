# Quality Memory

- Auto-fail on invented facts, generic chapter prose, repeated paragraph jobs, repeated sentence skeletons, contamination phrases, or hard/medium collapse.
- Chapter gate requires full chain artifacts plus a critic score of at least `10/12`.
- Review wrapper must contain the full validated chapter payload, not a partial stub.
- Scenario, `whatToDo`, and `whyItMatters` must be tone objects in flagship mode.
- Easy stays lean with exactly 3 takeaways and a flat recap. Medium uses singular `selfCheckPrompt`. Hard uses exactly 2 `selfCheckPrompts`.
- Validate with both structural lint and package-wide prose-audit expectations.
