# Style Memory

- Start from pressure, conflict, or a live question. Never start by narrating the chapter.
- Keep prose concrete, specific, and paraphrase-first.
- Every paragraph needs a distinct job and a single landing.
- No em dashes, no filler prestige language, no thesis-first openings, no sloganized competitive tone.
- Teach the mechanism directly. Do not drift into pack language, recap language, or generic coaching.
- Hard depth must preserve a real limit, contradiction, or threshold question rather than merely extending medium.
