An error feels easiest to notice when it is dramatic. A forecast misses badly. A file gets read in a way that later looks indefensible. The chapter's title asks for something stricter than surprise. If judgment matters, how should error inside judgment actually be measured?

That question matters because a miss does not stop being a miss just because the domain contains uncertainty. Judgment is not perfectly mechanical, but that does not mean error has to remain a vague complaint. A serious reading can still be compared against a steadier or more defensible reading. The point is not to erase ambiguity. It is to make misses visible enough to inspect.

This continues the previous chapter's boundary work. Once we know where judgment is active, we can stop treating every bad feeling about a decision as the same kind of problem. Some disappointment is not error. Some disagreement is not enough. But some misses are real enough to be measured even if the target is not perfectly exact.

That distinction changes the tone of the discussion. Error is no longer just a moralized word for failure. It becomes an object of inquiry. The reader has to ask what the judgment delivered, what a steadier reading might have delivered, and how large the gap really is. Without that move, noise stays atmospheric and hard to study.

The chapter still needs a limit. Measuring error does not grant perfect certainty, and it does not remove judgment from judgment. The domain can remain difficult while error remains inspectable. That is the tension the chapter has to preserve.

Once error is visible in that stricter way, the next step becomes possible. Noise can be analyzed as a pattern rather than treated as one loose complaint about inconsistency.
