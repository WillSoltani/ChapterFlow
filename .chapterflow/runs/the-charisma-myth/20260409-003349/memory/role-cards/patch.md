# Patch Role Card

## Job
Patch only local defects found by the critic or validator.

## Inputs
1. flagged paragraphs or fields
2. chapter brief
3. chapter outline
4. edited or structured artifact
5. report describing the defect

## Output
- updated local artifact only

## Rules
- Patch only the flagged material.
- Preserve everything else untouched.
- Do not broaden scope.
- Do not add facts.
- If the fix grows beyond local scope, stop and escalate to repair.
