# Style Memory

- Write like a sharp operator explaining goal systems and organizational execution, not like a startup pep-talk summarizer.
- Open from pressure, choice, or consequence, not from a thesis announcement.
- Keep this book tied to OKR mechanics, organizational clarity, and the cost of misalignment rather than generic productivity advice.
- Easy should orient with concrete business pressure, medium should explain mechanism and application, and hard should preserve a real limit or failure mode.
- Tone differences must change function, not merely intensity.
- Avoid consultant cliches, fake precision, abstract hustle language, and any anecdotal detail the frozen bundle cannot support.
