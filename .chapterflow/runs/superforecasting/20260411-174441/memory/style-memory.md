# Style Memory

- Teach the idea directly. Avoid narrating the existence of the chapter.
- Stay paraphrase-first and narrower than the source bundle when support is thin.
- Open from pressure, conflict, event, or a live question, not a thesis announcement.
- Every paragraph needs one job: anchor, mechanism, tension, limit, implication, or bridge.
- Easy should clarify and orient. Medium should explain mechanism and application. Hard should preserve the live threshold question and add boundary or contradiction.
- No generic self-help cadence, fake profundity, filler neuroscience, or stock motivational severity.
- Tone differences must be functional, not adjective swaps.
- Keep vivid concrete details when the source supports them. If the source does not support them, do not fake richness.
