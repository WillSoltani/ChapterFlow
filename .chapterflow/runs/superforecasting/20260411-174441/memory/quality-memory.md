# Quality Memory

- Chapter gate requires the full artifact chain: brief, outline, quiz blueprint, source sidecar, canonical draft, edited draft, critic report, structured chapter, quiz, validation report, validated chapter, review package, reading metrics, and sealed hash.
- Auto-fails: invented facts, generic chapter logic, repeated paragraph jobs, repeated endings, hard-as-longer-medium, contamination phrases, tone collapse, empty quiz, or source-splice leakage.
- Converter surfaces must do distinct jobs. `moreDetails` deepens instead of restating. Review cards, recap, prompts, and implementation plan cannot echo each other.
- Scenario fields must be tone objects. Quiz explanations must teach mechanism, not rephrase recap.
- If the critic or validator exposes local issues only, patch narrowly. If the problem is conceptual or package-wide, reroute and repair before proceeding.
