# Style Memory

- Teach the idea directly instead of narrating the chapter.
- Stay concrete, specific, and chapter-bound.
- Open from pressure, event, or live tension, not thesis summary.
- Keep paragraph jobs distinct and endings unsloganized.
- Easy should clarify, medium should explain mechanism, hard should add boundary, cost, or contradiction.
- Competitive tone must stay credible and severe without drifting into poster language.
- No fake-deep abstraction, filler mechanism language, or generic business cliches.
