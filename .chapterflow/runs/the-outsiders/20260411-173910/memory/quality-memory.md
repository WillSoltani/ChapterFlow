# Quality Memory

- Use only frozen support and narrow inference.
- Hard-fail on contamination phrases, repeated sentence skeletons, hard-medium collapse, or plain-string scenarios.
- `moreDetails` must deepen rather than restate.
- Review cards, recap, prompts, and implementation surfaces must do different jobs.
- Quiz must contain 10 real questions with 3 choices each and varied explanation openers.
- Review wrapper must contain the full validated chapter payload, not a partial chapter object.
