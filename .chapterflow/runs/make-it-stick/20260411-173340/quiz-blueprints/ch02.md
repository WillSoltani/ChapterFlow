# Chapter Quiz Blueprint

Chapter: To Learn, Retrieve

Core concepts to test:
- retrieval builds learning rather than only measuring it
- repeated exposure is weaker than reconstruction from memory
- low-stakes testing and self-quizzing can strengthen retention
- failed recall can be productive if it leads to correction and another attempt
- retrieval is powerful but not the same as punishment or pressure-heavy testing

Bloom ceiling:
- highest justified level for this chapter: analyze

Question plan:
- q01: core recall of what retrieval is doing in the chapter
- q02: contrast between rereading and self-quizzing
- q03: application to a classroom low-stakes quiz
- q04: workplace transfer about training that never required recall
- q05: why struggle during recall can still help learning
- q06: misreading about retrieval meaning high-pressure exams
- q07: personal-study scenario involving flashcard misses and repair
- q08: bridge question toward spacing and interleaving
- q09: synthesis on why retrieval is more than measurement
- q10: threshold question about support, correction, and frustration

Distractor notes:
- tempting wrong answer type 1: retrieval treated as only assessment
- tempting wrong answer type 2: difficult recall treated as evidence the method is failing

Explanation diversity notes:
- avoid repeated openers
- one explanation should stress reconstruction, another correction, another low-stakes classroom use
- at least one explanation should protect against the misconception that retrieval means punitive testing

CorrectIndex plan:
- keep distribution roughly balanced across 0 / 1 / 2
