# Style Memory

- Prose first, schema later.
- Keep reader-facing writing concrete, specific, and teachable.
- Do not sound like a study guide, a lecture transcript, or a motivational speech.
- Avoid thesis-first openings such as `This chapter`, `In this chapter`, or slogan-first claims.
- Easy should feel easier, not like thinned-out medium.
- Medium and hard must deepen rather than restate.
- Use tone objects for all required reader-facing surfaces.
- Avoid contamination phrases, recap replay, repeated endings, and generic coaching tails.
- Preserve chapter distinctness through mechanism, friction, and consequence.
