# Quality Memory

- No chapter may skip brief, outline, quiz blueprint, source sidecars, writer, editor, critic, prose audit, converter, quiz, validator, validated chapter, review package, reading metrics, or continuity seal.
- Review wrapper must contain the full validated chapter JSON as its single `chapters[0]` payload.
- Run prose audit before chapter gate and fail repeated sentences, repeated endings, review-card echo, hard/medium overlap, thesis-first openings, generic prompts, and generic implementation plans.
- Paraphrase-first unless exact quote support exists in the frozen authorized bundle.
- Claims unsupported by the frozen bundle must be cut or narrowed.
- Chapters 1 and 2 establish the quality floor for later waves.
- Release assembly must use validated chapter JSONs only.
