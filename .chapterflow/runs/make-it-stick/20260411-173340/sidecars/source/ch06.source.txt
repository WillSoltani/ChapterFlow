Core claim:
- Matching instruction to a preferred learning style is not the main route to stronger learning.
- Representation should fit the material, and instruction should account for prior knowledge and active processing.
- Retrieval, explanation, and evidence-backed design matter more than style labels.

Distinct mechanism:
- The chapter redirects attention from style labels to design choices that fit the content and the learner's actual preparation.
- It treats preference as weaker than evidence.
- It keeps learner differences visible by emphasizing prior knowledge and task demands instead of style mythology.

Required anchors:
- Preference is not proof of stronger learning.
- Material and representation should fit each other.
- Prior knowledge and active retrieval matter more than style labels.

Common misreadings:
- Learner differences do not matter.
- Visual or verbal tools are useless.

Specific applications:
- Use diagrams, words, or demonstrations because the content calls for them.
- Check background knowledge before blaming a style mismatch.
- Build retrieval and explanation into lessons.

Hard-edge requirement:
- Hard mode must reject the myth without collapsing into one-size-fits-all teaching.

Threshold question:
- What should guide instruction if not a simple style label?
