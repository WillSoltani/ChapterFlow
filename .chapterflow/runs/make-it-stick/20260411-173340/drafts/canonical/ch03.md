# Mix Up Your Practice

Once learners accept retrieval, a new temptation appears. They can still practice in ways that feel smooth because one problem type or one drill repeats until the right response starts to feel automatic. The session looks productive, and in one sense it is. But the comfort of blocked practice can hide a weakness: the learner may be getting better at repeating the same move, not at noticing which move fits when the situation changes. This chapter argues that mixing practice helps because it forces that choice.

Blocked practice makes the current run easier to manage. The learner solves the same kind of equation again and again, repeats the same response in a training drill, or rehearses one passage until it settles into muscle memory. That repetition can improve short-run performance. The problem is that the learner is not always being asked to identify what kind of problem this is. The answer pattern is already implied by the block itself. Interleaving changes that condition. When similar but distinct cases are mixed together, the learner has to notice the differences and decide which response applies here.

That discrimination is the chapter's real mechanism. Mixed practice is not useful because variety is exciting. It is useful because later performance depends on selection. Real exams, real work, and real performance settings rarely arrive labeled in neat blocks. The learner has to read the situation, compare it with alternatives, and choose the right tool. Interleaving gives practice a shape that resembles that later demand more closely than uninterrupted repetition does.

This is also why mixed practice can feel worse in the moment. Performance gets less smooth because the learner is no longer riding the same pattern. Each new item asks for recognition and choice. That friction can make the session look weaker if smoothness is still the scorecard. The chapter argues that it is often the more honest scorecard because it exposes whether the learner can identify the underlying pattern instead of only repeating a familiar response.

But the chapter does not confuse mixing with chaos. Randomness by itself is not the goal. Learners still need enough structure to see the categories, compare nearby cases, and understand why one move fits better than another. Productive variation sharpens the eye. Unstructured overload only blurs it. The value of mixed practice comes from disciplined comparison, not from disorder for its own sake.

So the chapter asks for a practical redesign of practice. Mix problem types. Rotate related skills. Build sessions that require choice, not only repetition. Once that shift is accepted, the book can widen its view again. The next chapter steps back from one practice design move and asks a broader question: when does hard-feeling learning help, and when does difficulty stop teaching and start wasting effort?
