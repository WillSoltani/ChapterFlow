# Make It Stick

The book ends by turning a set of principles into a routine. Retrieval, spacing, interleaving, calibration, and a better response to mistakes are not isolated tricks. They reinforce one another. A learner retrieves after time has passed, mixes cases instead of living inside one block, checks what is actually known, repairs what fails, and keeps returning on a schedule that favors durability over cramming.

That is why making learning stick is a design problem. Durable learning rarely comes from one last-minute push or one favored tactic. It comes from building a system that repeatedly asks memory to work honestly. The methods help together because each one protects against a different illusion: fluency, recency, blocked comfort, and false confidence.

The chapter therefore closes in practical terms. Students, teachers, and self-directed learners need routines that revisit material, mix practice, demand explanation, and keep calibration honest. Learning lasts when the routine keeps asking for retrieval and repair long after the first exposure feels familiar.

So the book ends where it has been heading all along. Better learning is not mysterious. It is designed. What lasts is built through repeated honest practice rather than through comfort, cramming, or confidence by feel.
