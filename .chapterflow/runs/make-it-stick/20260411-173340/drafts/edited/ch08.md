# Make It Stick

The closing chapter turns the book's ideas into a routine. Retrieval, spacing, interleaving, calibration, and response to mistakes work best together. They are not separate tricks to remember only when convenient.

Durable learning is therefore a design problem. The learner returns after delay, mixes cases, explains without cues, checks what is actually known, and repairs what fails. Each method protects against a different illusion of mastery.

So the book ends with a practical standard. Learning sticks when the routine keeps asking memory to work honestly over time. What lasts is built through repeated retrieval, mixed practice, honest checks, and a willingness to repair weak spots instead of hiding them.
