# Mix Up Your Practice

Practice can still mislead even after a learner stops trusting passive review. Repeating one kind of problem or drill in a single uninterrupted block often makes performance look cleaner than it will be later. The learner gets faster because the same move keeps showing up. This chapter argues that mixed practice matters because later success depends on choosing the right move, not only on repeating one familiar one.

Blocked practice can improve the current session. A student solves the same equation type again and again, a trainee repeats one response script, or a musician runs one passage until it settles. The weakness is not that repetition does nothing. The weakness is that the block itself often tells the learner which response to use. Interleaving changes that. When related but distinct cases are mixed together, the learner has to identify what kind of problem this is and what action fits here.

That act of discrimination is the chapter's main mechanism. Mixed practice is not valuable because variety is exciting. It is valuable because exams, work, and performance settings require recognition and selection under changing conditions. Interleaving trains those choices more directly than uninterrupted repetition does.

This is why mixed practice can feel worse while teaching more. The session loses some of its smooth rhythm because each item asks for comparison and choice. If smoothness is still the scorecard, mixed practice can look weaker. The chapter says that this rougher feeling is often more honest because it reveals whether the learner can actually tell one case from another.

The chapter keeps one boundary clear. Mixing is not the same as random chaos. Learners still need enough structure to see the categories, compare nearby cases, and understand why one response fits better than another. Productive variation sharpens the eye; disorder by itself only blurs it.

So the practical shift is straightforward: mix related problems, rotate nearby skills, and design practice that requires choice instead of only repetition. That sets up the next chapter's broader question. If some harder-feeling practice helps learning, how do you tell a desirable difficulty from a useless one?
