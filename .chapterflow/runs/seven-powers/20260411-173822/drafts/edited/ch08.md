The earlier chapters describe what power looks like once it exists. Helmer's chapter on the path to power changes the question. It asks how a firm begins moving toward a protected position in the first place, and it starts with a hard rejection: operational excellence is not strategy.

That does not dismiss execution. Running well still matters. But better execution inside the same exposed game does not create a barrier by itself. A firm can become faster, cleaner, and more disciplined and still remain easy to match if it is only playing the existing terms more skillfully than rivals.

This is why the chapter turns to invention and crux choice. Firms often need a directional move that changes the path they are on. The move matters not because it is merely novel, but because it opens a route toward a barrier that did not exist before. That is the difference between a strategic move and a better version of "me too."

The subtitle makes the warning explicit. Me-too positioning is insufficient because it leaves no barrier. If the offer is only imitation with sharper execution, rivals can usually answer in kind. The business may improve its current position for a while, but it has not changed its deeper exposure.

Strategy dynamics therefore asks a different question from strategy statics. Instead of asking which moat already exists, it asks what move could begin building one. Invention and crux choices matter when they redirect the firm toward a position that can later become protected.

This chapter is a disciplined bridge, not a motivational speech. It narrows attention to moves that change the route to power rather than polishing the same vulnerable game. The final chapter will organize those routes by stage and timing in the Power Progression.
