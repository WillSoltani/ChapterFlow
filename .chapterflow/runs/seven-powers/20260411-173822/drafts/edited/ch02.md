Big audiences get mistaken for strong networks all the time. Hamilton Helmer's second numbered chapter starts by cutting through that confusion. A product does not gain network power merely because many people have heard of it or signed up for it. It gains network power when each additional user makes the product more valuable for other users. The distinction sounds small. Strategically it is not.

This chapter changes variables from the one before it. Scale economies worked through cost. Network economies work through user value. A network grows stronger when participation increases usefulness inside the network itself. More members can mean more people to reach, more likely matches, more relevant interactions, or a richer set of complements built around the same user base. The benefit is not that the operator gets cheaper. The benefit is that the user gets more from belonging to the leading network.

Helmer is careful not to let that idea become mystical. Networks have character, and that character creates boundaries. The frozen notes use Facebook and LinkedIn for exactly this reason. Both can be powerful networks without one automatically swallowing the other, because personal interaction and professional interaction are not the same thing. A larger network in one domain does not automatically dominate a differently bounded network in another. Network power depends on what kind of participation the user actually values.

That boundedness matters because loose talk about network effects often assumes one giant winner everywhere. Helmer's version is more disciplined. Some networks do produce winner-take-most pressure, especially when early product quality is high and users cluster quickly around the same destination. In those cases, the leading network becomes more attractive because the other users are already there. A challenger is not just building a rival product. It is trying to persuade people to accept a thinner, less useful network while it catches up.

Complements can deepen that advantage. The frozen notes mention indirect network effects, where the leader attracts more or better complements because it already has the stronger user base. That could mean better tools, more integrations, or more supporting participants around the core network. The point is reinforcement. Once the leading network attracts stronger complements, the user's reason to stay gets stronger, and the follower's catch-up problem gets worse.

Still, Helmer does not offer a universal monopoly story. Networks can be strong without being all-consuming. If users can join multiple networks easily, if the network's purpose is narrow, or if the character of the network differs enough across contexts, the barrier may be weaker than the headline suggests. The real test is tougher: does more participation make the offering more useful to other users, and does that reinforcement make the leader meaningfully harder to challenge?
