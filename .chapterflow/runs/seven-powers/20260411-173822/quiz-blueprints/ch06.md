- highest justified level for this chapter: analyze and apply

- q05: school lab access scenario

- q07: local scarce expert scenario
- q08: analyze why substitute availability weakens the barrier
- q09: deeper synthesis on patent/talent/resource logic
- q10: bridge question toward process power

Distractor notes:

- tempting wrong answer type 2: scarcity assumed without checking substitutes

Explanation diversity notes:

- each direct explanation must begin differently
- explanations should name independent value, equivalent access, or the missing barrier
