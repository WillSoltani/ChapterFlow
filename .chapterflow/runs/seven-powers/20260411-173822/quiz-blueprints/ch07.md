# Chapter Quiz Blueprint

Chapter: Process Power
Core concepts to test:
- process power is rare
- interlocking activities yielding lower cost or better product
- prolonged commitment needed for rival replication
- distinction between system power and ordinary operational excellence
- one visible routine is not the whole moat

Bloom ceiling:
- highest justified level for this chapter: analyze and apply

Question plan:
- q01: basic definition of process power
- q02: identify interlocking activity logic
- q03: distinguish process power from operational excellence
- q04: named work scenario on visible tactic versus system
- q05: school capstone workflow scenario
- q06: student org copycat scenario
- q07: local service consistency scenario
- q08: analyze why prolonged commitment matters
- q09: deeper synthesis on copying one routine
- q10: bridge question toward path to power

Distractor notes:
- tempting wrong answer type 1: efficiency mistaken for process power
- tempting wrong answer type 2: one best practice mistaken for full system moat

Explanation diversity notes:
- avoid repeated openers
- each direct explanation must begin differently
- explanations should name the interlocking system, replication burden, or missing barrier
