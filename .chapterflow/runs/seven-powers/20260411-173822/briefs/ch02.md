Core Claim:
Network economies create power when each additional participant raises the value of the offering for other users, making the leader more attractive as it grows. Helmer's chapter is careful that this is not generic popularity. The network must have a character and a boundary, and the value loop has to reinforce the incumbent in a way followers struggle to match. The barrier comes from the difficulty of assembling a rival network with comparable participation, complement quality, and user relevance at the same time.

What Makes This Chapter Distinct:
This is the first chapter where the benefit is not lower cost but higher user value. It is also the chapter that forces the reader to stop talking loosely about "network effects" and instead ask what kind of network is involved, what its boundaries are, and why users do not simply multi-home into rival networks without consequence.

Author Logic Chain:
First the author defines network economies as a product becoming more valuable to one customer when more customers use it.
Then he stresses that not every network is the same; boundaries and user purpose matter.
Then he shows why early product quality and user concentration matter in winner-take-most settings.
Then he clarifies that complements can deepen the advantage when the leading network attracts more or better complements.
Then he leaves the reader with a narrower test: the network must strengthen user value and harden follower disadvantage at the same time.

Frameworks or Terms Introduced:
Network economies: value rises for one user as more users join.
Boundedness: network value depends on the specific character of the network, not all users everywhere.
Complement effect: more or better complements cluster around the leader and deepen usefulness.
Multi-homing pressure: users may join more than one network, so the barrier depends on how concentrated value becomes.

Specific Applications:
- Distinguishing a real network from a simple audience business.
- Testing whether a marketplace, school club platform, or professional directory becomes more useful as participation deepens.
- Recognizing when complements strengthen a leading platform instead of merely decorating it.

Common Misreadings:
- treating every social product as automatically powerful
- assuming bigger audience equals network economies even when users do not increase each other's value
- ignoring network boundaries and claiming one giant network beats all others by default

Counterarguments or Limits:
Network economies weaken when the network is easy to multi-home, when the user purpose is thin, or when the network boundary is narrow enough for multiple leaders to coexist. Hard depth should preserve the tension that some networks are powerful without being universal monopolies. Keep the chapter away from generic platform hype.

Previous Chapter Bridge:
Scale economies made the business cheaper as volume rose. Network economies change the mechanism: more users make the offering itself more valuable.
Next Chapter Bridge:
After a power based on user participation, the next chapter turns to a different barrier altogether: a newcomer whose superior model incumbents cannot copy without hurting themselves.
