# Source Discovery

## Book

- Title: Never Eat Alone
- Author: Keith Ferrazzi
- Locked work edition: 2014 expanded and updated Crown edition
- Run: `.chapterflow/runs/never-eat-alone/20260411-214036`

## Discovery path

1. Checked official publisher sources first.
2. Located the current Penguin Random House and Penguin Random House Higher Education pages for the expanded edition.
3. Located the authorized Google Books listing for the same 2014 edition and extracted the visible contents lines.
4. Cross-checked the existence of the earlier non-expanded edition family in Google Books.
5. Used narrow secondary chapter-map sources only to complete the full numbered chapter sequence where the visible Google Books contents page truncates.

## Freeze decision

The run locks the 2014 expanded and updated edition because it is the current in-print English edition, it has the strongest authorized preview support, and its chapter structure is the one consistently reflected by the official current publisher materials. The earlier 2005 edition remains relevant historically, but using it would create avoidable chapter-map drift for a run grounded in the currently supported edition family.
