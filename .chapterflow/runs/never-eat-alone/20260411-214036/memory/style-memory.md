# Style Memory

- Sound like a sharp human explainer, not a polished content machine.
- Lead with pressure, scene, or tension, not a thesis announcement.
- Favor concrete social situations over abstract networking advice.
- Keep paragraphs doing distinct jobs: anchor, mechanism, tension, limit, implication, bridge.
- Teach directly. Avoid narrating "the chapter" in reader-facing content.
- Easy should feel like a usable doorway, not compressed medium.
- Medium must explain mechanism and application.
- Hard must add boundary, contradiction, cost, or failure mode.
- Tone differences must be functional, not adjective swaps.
- Avoid corporate speak, generic self-help phrasing, and poster lines.
- Stay paraphrase-first and narrower than the source support whenever the freeze is thin.
