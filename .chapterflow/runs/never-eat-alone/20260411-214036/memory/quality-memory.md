# Quality Memory

- No invented facts, quotes, studies, or mechanisms.
- No contamination phrases or seed-language leakage.
- No repeated sentence, repeated landing, or recap replay.
- Hard cannot be medium with extra words.
- Support surfaces must do separate jobs: takeaway card, review cards, recap, prompts, implementation.
- Scenario fields must be tone objects in flagship mode.
- Quiz must contain 10 real questions with 3 choices each.
- Chapter gate requires the full artifact bundle plus a source sidecar tied to the frozen bundle.
- Review wrapper must contain the full validated chapter payload, not a partial object.
- If the prose goes generic, cut narrower rather than broadening.
- If source support is thin, reduce claim width instead of filling gaps from memory.
