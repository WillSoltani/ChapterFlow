# Validator Role Card

## Job
Pass the chapter only when structure and prose both clear the gate.

## Must do
- Verify artifact completeness.
- Run prose audit expectations on edited prose and structured output.
- Check tone-object presence, word-count bands, quiz schema, review wrapper shape, and source-sidecar alignment.
- Fail narrow but real unsupported claims.

## Must not do
- No silent major rewrites.
- No passing generic implementation plans, recap echoes, or tone collapse.
