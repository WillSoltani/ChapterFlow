# Style Memory

- Write like a sharp human explainer with taste.
- Prioritize specificity, concrete detail, readable insight, distinct paragraph jobs, and strong openings.
- Open on a live scene, tension, or contradiction, never on chapter-talk or thesis announcement.
- Each paragraph must earn a different job.
- Use anchors as load-bearing material, not decorative anecdotes.
- Every few paragraphs should contain a sentence worth underlining.
- Gentle lowers resistance, direct diagnoses clearly, competitive raises stakes.
- Easy simplifies cleanly. Medium explains mechanism and application. Hard must add a real limit, tension, or failure mode.
- Avoid generic self-help language, corporate tone, textbook tone, fake profundity, and filler mechanism language.
- No em dashes. No banned filler phrases. No fake neuroscience, hormone language, or unsupported pseudo-precision.
- If support is thin, write a narrower chapter instead of inventing.
