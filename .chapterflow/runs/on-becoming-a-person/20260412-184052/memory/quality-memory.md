# Quality Memory

- No chapter can skip brief, outline, quiz blueprint, source sidecar, writer, editor, critic, prose decision, converter, quiz, or validator.
- No validated artifact may be created before the full chapter chain exists.
- Critic target is at least 10/12 with no auto-fails.
- Source sidecars must derive from the frozen bundle and stay narrower than unsupported recall.
- Review packages must wrap the full validated chapter JSON, not a partial chapter object.
- In flagship mode, scenarios, whatToDo, and whyItMatters must all be tone objects.
- Empty quizzes, identical tone variants, contamination phrases, repeated package-level prose, and hard/medium collapse are immediate fails.
- Release later assembles from `validated/*.chapter.json` only, with sealed hashes preserved.
