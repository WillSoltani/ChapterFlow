# Style Memory

- Teach the idea directly instead of narrating the chapter.
- Start from pressure, tension, relation, or a live question, not thesis-first summary.
- Stay specific, concrete, and paraphrase-first because the frozen source bundle is thinner than a full text.
- Keep paragraph jobs distinct: anchor, mechanism, tension, limit, implication, bridge.
- Easy must orient without theory stacking. Medium must clarify mechanism and application. Hard must add boundary, contradiction, or failure mode.
- Competitive tone should sharpen consequence without sounding theatrical or combative.
- No em dashes, fake science, made-up anecdotes, or generic self-help uplift.
- Reader-facing support surfaces must not echo each other or reuse the same stems.
