# Validator Card

- Fix mechanical issues directly, but do not flatten prose to force a pass.
- Run lint and prose audit before writing a validated chapter.
- Fail empty quizzes, string scenarios, tone collapse, contamination, source splice, and hard/medium overlap immediately.
- If support surfaces are structurally valid but templated, duplicated, or generic, escalate to repair.
- Validate the review wrapper against the full validated chapter payload.
