# Source Freeze Report

## Frozen bundle

- `book-source.txt`: frozen source bundle summary with metadata, chapter map, and source notes
- `toc.json`: canonical chapter order for the locked edition
- `sidecars/source/source-heading-index.json`: chapter heading index for chapter-local sidecar generation
- `manifests/source-ledger.json`: full source ledger
- `manifests/edition-lock.json`: edition decision and rationale

## Authority order for chapter work

1. Locked 1961 Houghton Mifflin chapter order and chapter scope
2. Open Library authorized preview chapter map and page starts
3. Frozen bundle summary and heading index
4. Secondary summaries only where preview support is thin

## Guardrails applied

- No pirate mirrors or unauthorized reposts
- No mixing of introduction-only material into the numbered chapter run
- No exact quotation unless directly supported by the frozen preview bundle
- No chapter invention beyond frozen sources

## Risk notes

- Source support is strongest for chapter order, titles, and book-level framing, but thinner for paragraph-level details.
- Early chapters are better supported because the authorized preview exposes chapter 1 excerpt support and multiple summaries cover Rogers's core client-centered commitments.
- Later chapter briefs should remain conceptually sharp and narrower rather than over-claiming examples or anecdotal specificity not present in the frozen bundle.
