# Quality Memory

- Reject any passage that could be dropped into another chapter with little change.
- Reject repeated sentence skeletons, repeated endings, repeated paragraph landings, and recap/card echo.
- Hard cannot be medium with extra words.
- Support surfaces must each do different work.
- Implementation advice must be chapter-specific, not generic coaching.
- Quiz items must test judgment and use plausible distractors.
- No contamination phrases from briefs, validators, or internal pack language.
- If prose feels smoother than the source support allows, cut it.
- Validation must fail any identical tone objects, plain-string scenarios, empty quiz, or source-splice leakage.
