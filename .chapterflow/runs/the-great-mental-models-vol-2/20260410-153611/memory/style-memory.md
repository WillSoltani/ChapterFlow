# Style Memory

- Write like a sharp human explainer with taste.
- Specific beats generic. Concrete beats abstract. Insight beats padding.
- Open with live tension, a scene, or a perceptual problem, not a thesis announcement.
- Keep paragraph jobs distinct: anchor, mechanism, tension, limit, implication, or bridge.
- Easy should orient and clarify. Medium should explain mechanism and application. Hard should add limit, contradiction, boundary condition, or synthesis.
- Tone differences must be functional, not adjective swaps.
- Reader-facing prose should almost never talk about "this chapter."
- Avoid generic self-help, textbook voice, corporate voice, fake profundity, chest-thumping, and planning-note residue.
- No em dashes. No filler science. No made-up quotes. No unsupported anecdotes.
- If support is thin, make the prose narrower, shorter, and more chapter-specific.
