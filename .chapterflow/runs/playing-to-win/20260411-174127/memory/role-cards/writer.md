# Writer Role Card

- Use only the brief, outline, and chapter source sidecar as factual support.
- Write one real prose chapter, not JSON and not EMH blocks.
- Start from strategic pressure or a vivid business choice.
- Make each paragraph do one primary job.
- Keep the chapter unmistakably about the current chapter's mechanism.
- Include at least one real limit or tension.
- Once a claim lands, move on.
