# Quality Memory

- No chapter may move past writer -> editor -> critic -> prose decision -> converter -> quiz -> validator.
- Chapter gate requires: critic at or above 10/12, no contamination, no tone collapse, no scenario-string violations, no empty quiz, and source sidecar alignment.
- Auto-fail if the chapter could fit another chapter, if hard is just longer medium, if support surfaces repeat each other, or if the opening is thesis-first.
- Use the paragraph-role ledger: anchor, mechanism, tension, limit, implication, bridge.
- Hard depth must keep the outline's threshold question alive and add at least two of boundary, contradiction, cost, hidden structure, synthesis, or failure mode.
- Review package must wrap the full validated chapter JSON exactly. No partial wrapper.
- Seal continuity hashes only after chapter lint, review-package lint, and artifact-guard checks are clean.
- For this run, Chapter 1 and Chapter 2 establish the baseline quality floor for later waves.
- Chapters 3 and 5 have thinner source support than the rest of the book; keep them tighter and narrower.
