Chapter Promise:
By the end, the reader should understand that strategy only becomes real when a company makes a coherent set of choices about how it intends to win.

Opening Move:
Open on the uncomfortable moment when a team says it has a strategy, but all it really has is ambition plus a pile of activity.

Paragraph Job Map:

Required Distinction or Mechanism:
The chapter's core mechanism is coherence. Strategy is not any single choice. It is a set of reinforcing choices that together create a path to winning.

Hard-Depth Tension:
Many organizations can name aspirations, markets, or capabilities. The deeper problem is whether those answers reinforce one another strongly enough to create a real strategic position instead of dressed-up intent.

Threshold Question:
How can you tell when a set of strategic answers actually forms a winning system rather than a loose collection of preferences?
