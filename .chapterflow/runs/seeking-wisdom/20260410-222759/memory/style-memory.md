# Style Memory

- Teach the idea directly, not the existence of the chapter.
- Open from pressure, event, or a live tension rather than thesis summary.
- Keep prose concrete, specific, and authored.
- Every paragraph must do one distinct job.
- Easy = clear doorway. Medium = mechanism plus application. Hard = boundary, failure mode, or tension.
- Avoid generic self-help language, inflated abstraction, slogan tails, and planning-note leakage.
- Use fewer anchors rather than fake-rich anchors when the source is thin.
