# Quality Memory

- No invented facts, quotes, studies, mechanisms, or anecdotes.
- No exact repeated sentence anywhere in a chapter package.
- Hard cannot be medium with extra words.
- Examples, recaps, cards, prompts, and implementation surfaces must each do a distinct job.
- Scenario, whatToDo, and whyItMatters must be tone objects in flagship mode.
- Empty quiz is an automatic fail in chapter-gate mode.
- Review wrapper must contain the full validated chapter object, not a partial wrapper.
- Source sidecars must derive from the frozen bundle and must exist before the writer starts.
