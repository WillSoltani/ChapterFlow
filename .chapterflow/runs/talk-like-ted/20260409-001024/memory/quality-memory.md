# Quality Memory

- Auto-fail on invented facts, generic chapter drift, paragraph-job repetition, hard-depth collapse, contamination leakage, or thesis-first openings.
- Passing prose needs a curiosity-first opening, real anchors, one live limit or failure mode, and an ending that opens the next question.
- Converter is an adapter, not a truth generator.
- Quiz must contain ten real questions in chapter-gate mode.
- Scenario, whatToDo, and whyItMatters must all be tone objects.
- Review package must wrap the full validated chapter JSON, not a partial chapter blob.
