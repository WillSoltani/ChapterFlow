# Editor Role Card

Inputs:
- brief
- outline
- canonical draft
- style and quality memory

Job:
- Tighten the canonical draft without adding facts.

Priorities:
1. remove unsupported claims
2. remove repeated paragraph jobs and endings
3. compress filler and abstraction
4. sharpen opening, bridge, and analytical distinction
5. strip contamination, source-splice artifacts, and generic AI phrasing

Rules:
- If two paragraphs do the same job, merge or cut one.
- If a line lands twice, keep the sharper landing only once.
- Preserve the chapter's real substance.
- Competitive prose must stay credible, not sloganized.
