# Edited Draft: ch15

Chapter 15 attacks Gaussian overreach. The bell curve is not the villain everywhere, but it becomes dangerous when it is used in outlier-driven domains as though extremes were marginal noise.

Taleb's point is jurisdiction. In Extremistan, rare events can dominate the story, so a model that downplays them manufactures fake comfort.

The chapter sets up the next move. If bad models survive this long, part of the reason is that human beings find tidy patterns and smooth shapes irresistible. Chapter 16 turns to that attraction.
