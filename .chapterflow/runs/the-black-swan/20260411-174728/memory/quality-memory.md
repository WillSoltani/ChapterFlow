# Quality Memory

- No invented studies, quotes, or mechanisms.
- No thesis-first breakdown openings.
- No repeated landing sentence across breakdown, recap, cards, prompts, or implementation surfaces.
- Hard cannot be medium with extra words.
- Examples must teach different lessons inside the chapter's mechanism.
- Review card backs must not echo the key takeaway card.
- Quiz questions must test judgment in situations, not thin recall.
- Review wrapper must wrap the full validated chapter JSON exactly.
