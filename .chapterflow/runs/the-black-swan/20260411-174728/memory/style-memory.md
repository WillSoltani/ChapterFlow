# Style Memory

- Teach the idea directly instead of narrating the chapter.
- Start from pressure, rupture, or a live question, not a thesis announcement.
- Keep Taleb sharp, concrete, skeptical, and allergic to fake precision.
- Prefer one hard mechanism over three airy abstractions.
- Medium should explain the machinery of a mistake.
- Hard should add a limit, contradiction, or hidden structure.
- Competitive tone must sound credible, not theatrical.
- Reinforcement surfaces must compress or test memory, not replay the breakdown.
