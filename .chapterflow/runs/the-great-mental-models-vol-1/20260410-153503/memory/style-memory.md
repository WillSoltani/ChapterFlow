# Style Memory

- Teach the idea directly, not the existence of the chapter.
- Start from pressure, event, friction, or a live question rather than thesis announcements.
- Keep prose concrete, authored, and specific to the model at hand.
- Easy opens the door. Medium explains mechanism plus application. Hard must add boundary, cost, contradiction, or synthesis.
- Avoid generic self-help drift, fake prestige language, stock transitions, and reusable template tails.
- Competitive tone should be sharp and credible, never sloganized.
- Reinforcement surfaces must do separate jobs: takeaways distill, recap compresses or retrieves, prompts activate, review cards test memory.
