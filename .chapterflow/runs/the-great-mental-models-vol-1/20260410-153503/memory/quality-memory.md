# Quality Memory

- Chapter gate requires the full artifact chain before validation can count.
- No chapter passes under 10/12 critic quality or with any prose-audit auto-fail.
- Hard depth cannot be medium expanded with extra words.
- Tone objects must differ in function, not adjective intensity.
- Implementation plans, recap items, review cards, and quiz explanations must not echo one another.
- Source support wins over fluency. If frozen support is thin, narrow the claim.
- Review package must wrap the full validated chapter JSON, never a partial wrapper.
