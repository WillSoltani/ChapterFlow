# Chapter 9 Quiz Blueprint

## Blueprint Intent
Test applied understanding of entrepreneurial judgment, not slogan recall.

## Coverage Targets
- Core claim coverage: no universal rules remove the need for judgment.
- Mechanism coverage: deal contingency, accountability-versus-creativity tension, context-sensitive decision making.
- Boundary coverage: discipline versus rigidity.
- Misreading coverage: anti-rigidity is not anti-standards.

## Question Set Plan
1. Judgment Check
- Prompt shape: choose the response that uses principles without pretending a slogan is enough.
- Correct-answer signal: names the context and makes a conditional call.
- Distractor pattern: overconfident rule application.

2. Contingency Check
- Prompt shape: deal or operating outcome still in motion.
- Correct-answer signal: acknowledges uncertainty and avoids premature certainty.
- Distractor pattern: acts as if the outcome is locked.

3. Paradox Check
- Prompt shape: accountability versus creativity tension.
- Correct-answer signal: preserves both standards and invention.
- Distractor pattern: picks one side as if it solves everything.

4. Misreading Guard Check
- Prompt shape: identify the statement that matches the chapter boundary.
- Correct-answer signal: no rules means no universal rulebook, not no discipline.
- Distractor pattern: excuses weak standards.

5. Application Check
- Prompt shape: a team wants one permanent answer for a changing problem.
- Correct-answer signal: choose the contextual decision and explain why the clean rule fails.
- Distractor pattern: one-size-fits-all best practice.

6. Transfer Check
- Prompt shape: apply the chapter to a non-startup setting.
- Correct-answer signal: use judgment, standards, and context together.
- Distractor pattern: treat the chapter as startup chaos permission.

## Scenario-Linked Items
1. Scenario 1 (dialogue/personal)
- Ask which response shows the trap of treating a neat rule as a substitute for harder judgment.
- Explanation must show why the cleaner answer is not the wiser answer.

2. Scenario 2 (predict_reveal/work)
- Ask reader to predict the consequence of acting as if a contingent deal outcome is already settled.
- Explanation must show how false certainty distorts the next move.

3. Scenario 3 (dilemma/school)
- Ask which option keeps accountability and creativity in play without freezing the team.
- Explanation must show the paradox and why a permanent answer fails.

4. Scenario 4 (before_after/personal)
- Ask which change marks real ownership after the rigid rule is dropped.
- Explanation must show the shift from compliance to judgment.

5. Scenario 5 (decision_point/work)
- Ask which decision reflects contextual thinking instead of rule worship.
- Explanation must show the surprising implication of choosing the less tidy move.

6. Scenario 6 (postmortem/school)
- Ask what the team learns when a past rule works in one setting but fails in another.
- Explanation must show cross-domain transfer without universalizing the rule.

## Explanation Rules (All Scored Items)
- Explain why the correct option matches chapter mechanism.
- Explain why each distractor fails operationally under the actual context.
- Keep explanations principle-bound, no trivia or source-splice language.

## Medium Prompt Blueprints
1. Activation Prompt A
- Ask for one current problem where a clean rule is tempting but context is changing.
- Require one immediate judgment call and the reason it fits the current situation.

2. Activation Prompt B
- Ask reader to name one standard they must keep and one rule they should stop applying blindly.

3. Self-Check Prompt A
- Question form only: Where are you using a clean rule to avoid making a harder judgment call?

4. Self-Check Prompt B
- Question form only: What standard would still matter even if the rule changes?

## Hard Prompt Blueprints
1. Hard Self-Check Tone Slot: Direct
- Prompt: Which rule are you protecting because it feels safer than reading the actual context?

2. Hard Self-Check Tone Slot: Competitive
- Prompt: If you keep forcing the wrong rule onto the wrong context, what decision breaks first?

3. Hard Prediction Prompt A
- Prompt: If you follow the tidy rule in a situation that has already changed, what is the likely cost by the next decision cycle?

4. Hard Prediction Prompt B
- Prompt: If you choose context over formula, what new responsibility does that create for the leader?

## Structured Recap Blueprint
1. Retrieve
- Prompt: State the chapter's rule about rules in one sentence.

2. Connect
- Prompt: How does context-sensitive judgment preserve discipline without freezing the team in formula thinking?

3. Preview
- Prompt: When does a principle stop being useful if the leader turns it into a rigid rule?

## Review Card Blueprint
1. Applied Recall Card
- Front: A team keeps asking for the one correct rule even though the situation keeps changing. What do you say?
- Back rubric: name the context, keep the standard, refuse false certainty.

2. Transfer Card
- Front: In a school or work setting, how do you keep accountability without pretending the same rule always fits?
- Back rubric: identify the paradox, choose the contextual move, preserve discipline.
