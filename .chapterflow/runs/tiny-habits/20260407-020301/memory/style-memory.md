# Style Memory

- Write like a grounded explainer, not a motivational slogan machine.
- Open with a scene, friction point, or concrete example rather than a thesis sentence.
- Keep Tiny Habits specific to BJ Fogg's behavior-design method: B=MAP, matching, ability, prompts, celebration, growth, untangling, and collective change.
- Easy should be welcoming and clean, medium should explain the mechanism, and hard should preserve a real boundary or failure mode.
- Tone differences should change how the idea lands, not merely swap adjectives.
- Avoid generic self-help uplift, fake precision, and any quote support the frozen bundle cannot prove.
