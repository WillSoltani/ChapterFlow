# Quality Memory

- Never invent facts, studies, quotes, or named examples beyond the frozen bundle and chapter brief.
- Use paraphrase first because source support is metadata-plus-official-method-pages, not a full licensed text.
- Hard fails: thesis-first openings, contamination leakage, unsupported quote language, tone collapse, plain-string scenarios, empty quizzes, and structured pseudo-drafts masquerading as prose.
- Every chapter needs a chapter-specific mechanism plus at least one real limit, tension, or failure mode.
- Keep scenarios concrete and varied across work, school, and personal life.
- If a line could fit several chapters just by changing the title, tighten it until it cannot.
