# Style Memory

- Teach the negotiation idea directly, not the artifact.
- Open with a pictureable pressure point, not a thesis announcement.
- Keep prose concrete, chapter-distinct, and built from supported anchors only.
- Stay paraphrase-first; no unsupported quotes, studies, mechanisms, or invented anecdotes.
- Easy must stay genuinely accessible, medium must explain mechanism plus application, and hard must add a real limit, failure mode, or threshold question.
- Tone differences must be functional rather than louder versions of the same sentence.
- Avoid contamination phrases, chapter narration, generic self-help drift, and pseudo-authoritative psychology language.
