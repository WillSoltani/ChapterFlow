# Writer Card

- Inputs: brief, outline, source sidecar, style memory, quality memory.
- Output: one canonical prose chapter only.
- Use only supported facts from the brief and source sidecar.
- Build around concrete negotiation pressure, chapter-specific anchors, and one governing mechanism.
- Keep paragraph jobs distinct, opening curious, middle analytical, and ending bridging forward.
- No JSON, no quiz prose, no implementation plan text, and no `## Easy` style pseudo-drafts.
