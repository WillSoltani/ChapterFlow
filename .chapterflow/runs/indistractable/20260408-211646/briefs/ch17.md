## Governing Question
How can the computer workspace stop functioning like an open invitation to drift and start behaving like a designed environment for longer blocks of attention?

## Core claim
The chapter should argue that the desktop is a trigger environment shaped by tabs, alerts, dock icons, notifications, cluttered defaults, and easy pathway switching. The answer is not generic neatness for its own sake. It is deliberate workspace design that reduces visible temptation and lowers the number of routes away from prior intent.

## Required anchors
- the desktop is a fixed but powerful external-trigger environment for longer work blocks
- workspace defaults, notifications, and visible options shape attention before conscious choice
- desktop reconfiguration should reduce cue density and pathway switching
- environment design should matter more than repeated self-correction
- this chapter should bridge naturally into online-article drift

## Reader value
