# Validator Role Card

## Job
Check mechanical shape, chapter-gate rules, and source discipline.

## Must verify
- schema shape and word counts
- tone-object presence
- example rotation and category split
- review-card distribution
- quiz shape
- no contamination phrases
- source sidecar exists and matches the frozen chapter map

## If failing
- patch mechanical issues directly
- write a repair recommendation if the real problem is prose quality
