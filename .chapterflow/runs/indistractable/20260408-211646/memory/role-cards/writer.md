# Writer Role Card

## Job
Write one canonical chapter in real prose before any structure or quiz work.

## Use
- chapter brief
- chapter outline
- chapter source sidecar
- style memory
- quality memory

## Requirements
- stay inside the frozen source bundle
- open with a scene, tension, or friction point, not a thesis announcement
- make every paragraph do a distinct job
- keep at least one live limit or friction point visible
- bridge naturally to the next chapter question

## Do not write
- JSON
- quiz questions
- review cards
- pseudo-draft headings
