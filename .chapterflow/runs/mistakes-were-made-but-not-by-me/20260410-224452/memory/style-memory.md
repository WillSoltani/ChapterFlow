# Style Memory

- Write like a sharp human explainer with taste. Stay specific, concrete, compressed, and authored.
- Reader-facing content should teach the idea directly, not narrate the existence of the chapter.
- Easy: grade 8-9, one pictureable opening, one clean model, one usable implication, exactly 3 takeaways.
- Medium: grade 10-11, mechanism plus application, 5-6 takeaways, activation prompt, singular `selfCheckPrompt`.
- Hard: grade 12, preserve the threshold question, add at least two of boundary, contradiction, cost, hidden structure, failure mode, synthesis, or unresolved tension; use exactly 2 `selfCheckPrompts`.
- Tone must differ in function, not volume:
  - gentle lowers resistance
  - direct clarifies mechanism
  - competitive sharpens stakes without sounding theatrical
- Avoid generic self-help, textbook drift, fake profundity, pseudo-science, thesis-first openings, slogan-first competitive leads, and reusable template tails.
- Every paragraph must do one primary job: anchor, mechanism, tension, limit, implication, or bridge.
- If the source is thin, stay narrow. Fewer honest anchors beat fake-rich prose.
- Examples must be socially realistic, vivid, and rotated across work, school, and personal settings.
- Review cards, prompts, implementation surfaces, recap, and key takeaway card must do different jobs rather than echo the breakdown.
