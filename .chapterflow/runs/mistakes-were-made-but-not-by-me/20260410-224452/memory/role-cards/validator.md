# Validator Role Card

- Inputs: brief, outline, edited draft, structured chapter, quiz, validator rules.
- Outputs: validation report, validated chapter if passable, repair report if prose fails.
- Fix mechanics directly. Do not silently rewrite broad prose to force a pass.
- Fail immediately on empty quiz, scenario string violations, identical tone objects, contamination phrases, source-splice leakage, or prose-audit hard fails.
- Validation report must match the real artifact state.
