# Quality Memory

## Governing Checks
- Chapter must be unmistakably this chapter.
- Use load-bearing anchors where the source supports them.
- Keep one real tension, limit, or failure mode visible.
- Medium and hard must do materially different cognitive work.
- No contamination phrases, source-splice leakage, or structured pseudo-prose.

## Prose Audit Priorities
- No duplicate sentence within any reader-facing surface or across the chapter package.
- No repeated concluding beat.
- No repeated template tails across takeaways, recap items, prompts, cards, or implementation plan.
- `moreDetails` must deepen, not paraphrase.
- Review cards must not echo the key takeaway card.
- Recap retrieve must test memory, not summarize.
- Preview must ask for prediction, not act like teaser copy.

## Structural Requirements
- Scenario fields are tone objects.
- Easy has exactly 3 takeaways and flat `oneMinuteRecap`.
- Medium uses singular `selfCheckPrompt`.
- Hard uses `selfCheckPrompts` array of exactly 2 tone objects.
- Quiz must contain 10 questions with 3 choices each in chapter-gate mode.

## Chapter Gate Threshold
- Critic score at least 10/12.
- No auto-fails from quality gate or prose audit.
- Source sidecar exists and matches frozen bundle.
- Validated review package must wrap the full validated chapter JSON.
