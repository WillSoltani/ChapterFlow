# Style Memory

- Teach the idea directly, not the artifact.
- Open with a pictureable situation or tension, not a thesis announcement.
- Keep prose specific, concrete, and chapter-distinct.
- Use no unsupported studies, quotes, or mechanisms.
- Easy stays genuinely easy; hard must add a live limit, threshold, or contradiction.
- Tone differences must be functional, not adjective swaps.
- Avoid contamination phrases, generic life-coaching drift, and planning-note language.
