# Quality Memory

- Auto-fail any invented fact, unsupported quote, contamination phrase, thesis-first opener, hard-medium collapse, repeated sentence, repeated ending beat, or generic support surface.
- Critic threshold is at least 10/12 before conversion.
- Converter is an adapter: brief first, outline second, edited prose third.
- Review package must wrap the full validated chapter JSON, never a partial object.
- Quiz mode is `generate`, so empty quiz arrays fail.
- Scenario tone objects are mandatory in flagship mode.
- After each chapter passes, verify the full artifact bundle on disk, rerun gate checks, then seal the hash.
- After each wave, run artifact guard before starting the next wave.
