# Style Memory

- Write like a sharp human explainer with concrete nouns, direct verbs, and authored judgment.
- Open from pressure, conflict, or a live decision, not a thesis announcement.
- Keep paragraphs single-purpose and avoid repeated landings.
- Use `you` naturally but sparingly.
- Competitive tone should be severe and credible, not theatrical.
- Do not leak brief, outline, validator, or pack language into reader-facing prose.
- No em dashes, fake profundity, pseudo-science, filler strategy jargon, or recap-like restatement.
- Easy should orient cleanly, medium should explain mechanism and friction, hard should add limit, contradiction, cost, or threshold.
