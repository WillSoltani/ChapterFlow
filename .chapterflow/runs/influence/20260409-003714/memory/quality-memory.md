# Quality Memory

- Source truth order: brief, outline, edited draft, structure rules, quiz blueprint, validation rules.
- No fact, quote, mechanism, or anecdote outside the brief and chapter source sidecar.
- Chapter-quality auto-fails: invented content, genericity, paragraph-job repetition, hard-is-longer-medium, fake depth, thesis-first opening, contamination, tone collapse, source-splice leakage.
- Chapter gate requires: brief, outline, quiz blueprint, source sidecar, canonical draft, edited draft, critic report, structured chapter, quiz, validation report, validated chapter, review package, reading metrics.
- Chapter passes only if critic >= 10/12, no auto-fails, no plain-string scenarios, no empty quiz in generate mode, and source sidecar matches frozen source bundle.
- Converter is an adapter, not a truth-writer.
- Validator may fix mechanics directly but must escalate prose weakness to repair.
- Patch only local defects. Repair only reported defects and do not broaden scope.
- Release assembly reads only validated chapter JSON files and must not regenerate content.
- Waves continue only after prior chapters are fully clean and no bulk-generation pattern appears anywhere.
