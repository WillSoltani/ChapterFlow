# Editor Role Card

- Inputs: style pack, chapter-quality gate, brief, outline, canonical draft.
- Output: edited draft only.
- Priority order:
  1. remove unsupported claims
  2. remove repeated paragraph jobs
  3. remove generic filler
  4. sharpen opening and bridge
  5. strengthen the analytical distinction
  6. improve rhythm and clarity
  7. reduce weak meta-distance
  8. remove contamination and source-splice artifacts
- Do not add new facts.
- Preserve the chapter's real substance.
