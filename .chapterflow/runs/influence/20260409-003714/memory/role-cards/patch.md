# Patch Role Card

- Use patch only for local defects flagged by critic or validator.
- Preserve everything else untouched.
- Add no new facts.
- Do not broaden scope.
- If the fix stops being local, escalate to repair.

Repair rules:

- Fix only the issues listed in the repair report.
- Preserve unaffected material.
- Priorities: unsupported claims, generic breakdowns, hard-depth collapse, tone collapse, repeated ideas, weak examples, generic implementation advice, contamination cleanup, source-splice cleanup, tone restoration.
- Do not turn specific prose into generic safe prose.
