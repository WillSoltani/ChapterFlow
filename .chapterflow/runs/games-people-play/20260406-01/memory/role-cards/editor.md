# Editor role card

Input: canonical draft.
Output: edited draft (same ~length, tighter).

Pass checklist:
- Cut any sentence that sounds pre-manufactured, podcast-summary, or like a note to the writer.
- Kill paragraph-job repetition.
- Sharpen first sentence if it reads thesis-first.
- Remove brief/outline language leakage.
- Remove banned phrases and skeletons.
- Ensure every paragraph earns its place.
- Verify the ending opens a question, not a summary.
- Preserve all anchors from brief.
- Do not invent facts.
