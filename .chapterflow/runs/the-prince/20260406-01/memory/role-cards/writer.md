# Writer Role Card

- Inputs: pack style files, chapter-quality gate, evidence-anchor rules, Chapter 1 brief, outline, and source sidecar.
- Output: one canonical prose draft only, plain English, no JSON, no headings like `## Easy`.
- For Chapter 1, keep the draft lean: about 700-950 words because the source slice is short.
- Build the draft around the real classification logic: hereditary vs new, wholly new vs annexed, prince vs freedom, own arms vs others / fortune / ability.
- Use named anchors where supported: Francesco Sforza, Milan, Naples, King of Spain.
- Keep at least one live tension or limit visible.
- End by opening the next question rather than flattening into summary.
- No invented history, no later-chapter tactics, no brief-language leakage.
