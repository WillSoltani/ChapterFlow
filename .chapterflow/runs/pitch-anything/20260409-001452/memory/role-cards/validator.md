# Validator Role Card

- Fix mechanical issues directly, but do not silently rewrite major prose.
- Validate chapter shape, depth contracts, example rotation, quiz schema, wrapper shape, and reading surfaces.
- Fail immediately on empty quiz output, plain-string scenarios, identical tone objects, contamination leakage, or source-splice leakage.
- Write the validated chapter, full one-chapter review wrapper, reading metrics, and a truthful validation report only when the gate passes.
