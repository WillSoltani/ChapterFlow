# Source Discovery

## Goal

Freeze a lawful source bundle for `Built to Last: Successful Habits of Visionary Companies` before any chapter generation.

## Discovery outcome

- Full public-domain text: not available.
- Full authorized digital text: not available in the initial run window.
- Authorized preview: available via Google Books.
- Library preview cross-check: available via Open Library.
- Official concept support from the author: available via Jim Collins site.
- Chapter map cross-check: available via a secondary reference page.

## Working decision

Use an authorized-preview bundle anchored on the Google Books 2004 Harper Collins page, cross-checked with Open Library preview metadata and official Jim Collins concept pages for recurring ideas such as clock building and core values.

## Why no user question was needed

The book is not a translation case, and the observed edition differences do not materially alter chapter order or chapter intent. The run can lock the dominant accessible edition automatically.

## Support boundaries

- Exact quoting is allowed only where supported by the frozen preview text.
- For chapter content beyond the preview window, stay paraphrase-first and avoid claims that are not grounded in the frozen bundle.
- Secondary sources are used only to stabilize chapter naming and scope, not to introduce unsupported details.
