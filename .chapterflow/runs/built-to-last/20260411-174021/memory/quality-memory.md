# Quality Memory

- No chapter advances to structure until critic clears prose at 10/12 or better with no auto-fails.
- Auto-fails include invented facts, generic prose, repeated paragraph jobs, repeated endings, hard-depth collapse, contamination phrases, source-splice leakage, and thesis-first openings.
- Source sidecars must exist before writing and must derive from the frozen bundle.
- Structured output must keep scenario, whatToDo, and whyItMatters as tone objects.
- Easy: exactly 3 takeaways, no moreDetails. Medium: 5 to 6 takeaways plus singular selfCheckPrompt. Hard: 5 to 7 takeaways plus exactly 2 selfCheckPrompts.
- Quiz mode is generate, so every chapter needs a real 10-question quiz with 3 choices each.
- Review package must wrap the full validated chapter JSON exactly once.
- Hash sealing happens only after validation passes and artifact completeness is verified on disk.
