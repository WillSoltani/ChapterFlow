# Quality Memory

- A chapter passes only when the full artifact chain exists: pre-writer files, prose chain, structured chapter, quiz, validation report, validated chapter, review wrapper, reading metrics, and sealed continuity hash.
- Chapter-gate auto-fails include invented support, generic prose, paragraph-job repetition, hard-medium collapse, contamination leakage, empty quizzes, plain-string scenarios, identical tone objects, and source-sidecar mismatch.
- Support surfaces must do different jobs: takeaways compress, moreDetails deepen, review cards retrieve, recap retrieves/connects/predicts, implementation surfaces stay chapter-specific.
- Review packages must wrap the full validated chapter JSON, not a partial chapter object.
- Hashes seal only after validation passes, and later waves cannot begin until the previous wave is artifact-clean.
