# Quality Memory

- A chapter fails if it invents facts, quotes, or mechanisms, collapses hard into medium, repeats endings, or leaks pack language.
- Critic threshold is effectively 10/12 or better before conversion.
- No writer starts until brief, outline, quiz blueprint, and chapter-local source sidecars exist.
- Converter is an adapter, not a truth generator.
- Scenario, whatToDo, and whyItMatters must be tone objects in flagship mode.
- Quiz must contain 10 real questions with 3 choices each in chapter-gate mode.
- Review package must wrap the full validated chapter JSON, not a partial wrapper.
- Release can assemble only from validated chapter JSONs.
