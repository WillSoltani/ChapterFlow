# Style Memory

- Teach the idea directly, not the existence of the chapter.
- Start reader-facing prose with pressure, scene, or live tension, not thesis summary.
- Prefer chapter-specific anchors over abstract explanation.
- Easy stays clean and graspable; medium explains mechanism; hard adds limit, contradiction, or threshold.
- Tone differences must be functional:
  - gentle lowers resistance
  - direct clarifies mechanism
  - competitive sharpens stakes without sounding theatrical
- No filler neuroscience, fake precision, slogan endings, or generic coaching language.
- Reinforcement surfaces must do different jobs instead of replaying the breakdown.
- If the source is thin, stay narrower instead of inventing richness.
