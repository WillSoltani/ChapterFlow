# Style Memory

- Write like a sharp human explainer: concrete, selective, and unsentimental.
- Open on friction, contrast, or a live dilemma rather than thesis-first abstraction.
- Keep each chapter unmistakably tied to its mechanism, not to generic productivity advice.
- Easy should be genuinely simpler, medium should explain the mechanism cleanly, and hard should keep a real trade-off or limit alive.
- Tone differences must do work: gentle lowers resistance, direct clarifies, competitive sharpens stakes.
- Avoid breezy self-help filler, pseudo-wisdom, pack-language contamination, and repeated sentence skeletons.
