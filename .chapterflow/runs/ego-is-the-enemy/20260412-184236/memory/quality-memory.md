# Quality Memory

- No invented facts, quotes, or anecdotes beyond the brief.
- No thesis-first breakdown openings.
- No repeated sentence, repeated landing, or same-stem reinforcement surface.
- Hard must add a boundary, contradiction, or cost rather than extending medium with extra words.
- Examples must feel socially real and chapter-specific across work, school, and personal settings.
- Review cards, recap items, prompts, and implementation plans must do different jobs.
- Quiz distractors must be plausible and explanations must teach the chapter's actual mechanism.
- If support is thin, narrow the claim rather than smoothing over the gap.
