# Editor Card

- Inputs: brief, outline, canonical draft, style memory, quality memory.
- Output: edited prose draft only.
- Remove unsupported claims first.
- Compress repetition aggressively.
- Sharpen opening and bridge.
- Cut generic filler, planning-note residue, contamination language, and source-splice artifacts.
- Do not add new facts.
- Preserve the chapter's real substance while making each paragraph earn its job.
