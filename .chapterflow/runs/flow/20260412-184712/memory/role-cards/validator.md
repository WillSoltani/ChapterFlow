# Validator Card

- Inputs: brief, outline, edited draft, structured chapter, quiz, quality memory.
- Outputs: validation report and validated chapter when passable.
- Fix mechanics directly; escalate prose weakness to repair.
- Run lint and prose audit before passing.
- Fail immediately on empty quiz, plain-string scenarios, tone collapse, contamination, source splice, hard/medium overlap, repeated template tails, generic support surfaces, or fake support.
- Review wrapper payload must exactly match the full validated chapter JSON.
- Run semantic diversity checker after structural validation.
