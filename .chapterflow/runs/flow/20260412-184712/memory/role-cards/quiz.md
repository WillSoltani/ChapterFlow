# Quiz Card

- Inputs: brief, edited draft, structured or validated chapter, quiz blueprint.
- Output: valid quiz JSON only.
- Exactly 10 questions, 3 choices each.
- Prefer concrete judgment scenarios over abstract recall.
- Questions must test different principles.
- Explanations must teach the chapter mechanism, limit, or trap, not recap.
- No repeated explanation openers.
- Run quiz quality scorer after generation.
