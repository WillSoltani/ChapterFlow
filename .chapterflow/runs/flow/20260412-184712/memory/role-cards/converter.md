# Converter Card

- Inputs: brief, outline, edited draft, chapter-structure rules.
- Output: valid ChapterFlow JSON only.
- Facts come from brief; prose comes from edited draft.
- Easy / medium / hard must do materially different jobs.
- Keep key takeaway card, review cards, recap, prompts, implementation plan, and moreDetails distinct in function.
- Scenario, whatToDo, and whyItMatters must all be tone objects.
- No repeated sentences across the chapter package.
- Hard must preserve the outline threshold question and add new structure, not more words.
