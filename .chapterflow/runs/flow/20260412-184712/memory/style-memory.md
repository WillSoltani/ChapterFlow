# Style Memory

- Write like a sharp human explainer with taste: specific, concrete, compressed, authored.
- Teach the idea directly. Reader-facing content should almost never narrate `the chapter`.
- Open from pressure, event, conflict, or a live question. Do not open with thesis summary or slogan severity.
- Every paragraph needs one clear job: anchor, mechanism, tension, limit, implication, or bridge.
- Avoid generic self-help tone, corporate tone, textbook drift, fake profundity, filler mechanisms, and phrasey scaffolding.
- No em dashes.
- No invented facts, quotes, studies, or neuroscience overlays.
- Easy should clarify with one clean model and one usable implication.
- Medium should add mechanism, friction, and application.
- Hard should add boundary, contradiction, cost, failure mode, hidden structure, synthesis, or unresolved tension.
- Competitive tone must stay credible and concise, not poster-ready.
- Reinforcement surfaces must feel independently authored for the chapter, not templated.
- If the source is thin, stay narrow instead of inflating.
