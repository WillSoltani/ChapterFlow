# Quality Memory

- Chapter gate requires: brief, outline, quiz blueprint, source sidecar, canonical draft, edited draft, critic report, structured chapter, quiz, validation report, validated chapter, review package, reading metrics, and continuity hash seal after pass.
- No writer starts before brief, outline, quiz blueprint, and both source sidecar files exist.
- Auto-fails: invented support, generic chapter drift, repeated paragraph jobs, duplicate endings, hard-as-longer-medium, contamination phrases, scenario string violations, empty quiz in generate mode, tone collapse, source-splice leakage.
- Prose audit checks package-wide duplication, repeated template tails, review-card echo, generic moreDetails, generic prompts, generic implementation plans, thesis-first openings, slogan-first competitive openings, and medium/hard overlap.
- Converter is an adapter, not a new writer of truth.
- Quiz must have exactly 10 questions, 3 choices each, balanced correctIndex, and explanations that teach mechanism rather than recap.
- Validator may fix mechanics directly but must escalate prose weakness to repair.
- Review package must wrap the full validated chapter JSON exactly once.
- Later waves must be compared against the Chapter 1-2 baseline; stop if quality decay exceeds threshold.
- Release must assemble only from validated chapter JSONs.
