# Outline: ch11

## Governing principle

Availability bias begins when memorable examples start standing in for representative evidence.

## Canonical prose movement

1. Hook: what comes to mind fastest can feel more common, risky, or important than it really is.
2. Mechanism: vividness, recency, and emotion make some examples easier to recall than others.
3. Anchor: work, school, and personal judgments all become vulnerable when memory ease gets mistaken for frequency.
4. Application: people overestimate what is dramatic and underestimate what is quiet but typical.
5. Tension: memory fluency feels like evidence even when it is only salience.
6. Bridge: better judgment asks what evidence is representative, not only memorable.

## Depth intentions

- Easy: memorable examples can trick you into thinking they are common.
- Medium: vivid and recent examples distort probability and importance judgments.
- Hard: availability bias corrupts judgment when recall speed changes evaluation more than representative evidence does.

## Threshold question for hard

Am I judging by what is typical, or by what reached memory first?

## Example routing

- work: vivid project failures, dramatic client stories, recent incidents, or memorable presentations dominating planning
- school: recent examples, standout mistakes, dramatic case studies, or memorable classmates distorting judgment
- personal: travel fears, health worries, neighborhood stories, purchases, or family anecdotes overpowering base rates

## Reinforcement surfaces

- recap retrieve should ask why easy recall can feel like proof
- implementation plan should force one representative-evidence check after a vivid example grabs attention
