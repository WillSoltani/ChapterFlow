# Quiz Blueprint: ch28

- chapterId: ch28
- title: Base-Rate Neglect

## Concepts to test

1. base-rate neglect means specific case detail is overweighted relative to general frequency
2. vivid stories can feel more persuasive than population patterns
3. what usually happens is an essential part of interpreting any case
4. correction requires bringing the base rate back before concluding
5. fairer judgment combines the case with the broader pattern instead of replacing one with the other

## Question spread

- q01-q03: identify base-rate neglect in ordinary judgments
- q04-q06: named-character work or school cases where one case crowds out the wider pattern
- q07-q08: distinguish vivid case detail from base-rate context
- q09-q10: deeper transfer on restoring population-level reality before concluding

## Distractor policy

- tempting wrong answers should treat a vivid case as enough on its own
- another distractor should overcorrect by claiming individual detail never matters
- one distractor can confuse an unusual case with a representative one
