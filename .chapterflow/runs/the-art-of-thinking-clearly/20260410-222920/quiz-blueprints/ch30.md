# Quiz Blueprint: ch30

- chapterId: ch30
- title: The Anchor

## Concepts to test

1. anchoring means first numbers influence later judgment too much
2. an early figure can shape what feels plausible even if it is arbitrary
3. later adjustments often stay too close to the initial reference point
4. correction requires making an independent estimate before reacting
5. fairer judgment asks how the conclusion would look without the first number

## Question spread

- q01-q03: identify anchoring in ordinary judgments
- q04-q06: named-character work or school cases where first figures distort estimates
- q07-q08: distinguish useful reference points from arbitrary anchors
- q09-q10: deeper transfer on generating independent estimates before exposure

## Distractor policy

- tempting wrong answers should treat the first number as neutral just because it came first
- another distractor should overcorrect by claiming reference points never help at all
- one distractor can confuse adjustment with full independence
