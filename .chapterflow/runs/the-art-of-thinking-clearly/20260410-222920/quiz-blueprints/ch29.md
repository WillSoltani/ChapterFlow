# Quiz Blueprint: ch29

- chapterId: ch29
- title: Gambler's Fallacy

## Concepts to test

1. gambler's fallacy means thinking independent random events must balance out soon
2. streaks can create the false feeling that the opposite result is due
3. past random outcomes do not alter the odds of the next independent event
4. correction requires checking whether the process has memory or not
5. fairer judgment asks whether imbalance is real or only psychologically uncomfortable

## Question spread

- q01-q03: identify gambler's fallacy in ordinary randomness
- q04-q06: named-character work or school cases where streaks get overread
- q07-q08: distinguish independent randomness from self-correcting systems
- q09-q10: deeper transfer on checking memory, independence, and due-for-a-turn thinking

## Distractor policy

- tempting wrong answers should treat a streak as creating a debt the next result must repay
- another distractor should overcorrect by claiming all sequences are meaningless in every system
- one distractor can confuse true dependence with random independence
