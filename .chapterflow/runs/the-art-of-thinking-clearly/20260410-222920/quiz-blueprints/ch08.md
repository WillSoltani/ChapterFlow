# Quiz Blueprint: ch08

- chapterId: ch08
- title: Confirmation Bias (Part 2)

## Concepts to test

1. confirmation bias can shape judgments about people, not only abstract evidence
2. stereotypes feel convincing when confirming behavior is treated as typical and conflicting behavior as exceptional
3. social labels can distort work, school, and personal judgment by steering attention and memory
4. the bias does not require explicit hostility; it can run through ordinary sorting and expectation
5. correction requires individuating evidence and a clear standard for weakening the label

## Question spread

- q01-q03: identify stereotype-driven selective noticing in ordinary scenes
- q04-q06: named-character work or school cases where a label changes how later behavior is interpreted
- q07-q08: distinguish fast social sorting from fair evidence-based judgment
- q09-q10: deeper transfer on counterevidence, individuation, and weakening overconfident labels

## Distractor policy

- tempting wrong answers should treat one matching example as proof that the label is basically true
- another distractor should overcorrect by claiming all social pattern recognition is automatically invalid
- one distractor can confuse familiarity, status, or comfort with accurate judgment
