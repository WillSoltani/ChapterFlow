# Quality Memory

- No chapter may skip brief -> outline -> quiz blueprint -> writer -> editor -> critic -> prose audit -> converter -> quiz -> validator.
- Critic gate must hit at least 10/12 with no auto-fails.
- Prose audit auto-fails repetition, ending echoes, hard/medium collapse, generic support surfaces, slogan leads, and contamination leakage.
- Flagship mode requires tone objects for scenario, whatToDo, and whyItMatters.
- Easy has exactly 3 takeaways and a flat recap.
- Medium requires activationPrompt, singular selfCheckPrompt, and recap retrieve/connect/preview.
- Hard requires activationPrompt, exactly 2 selfCheckPrompts, predictionPrompt, and deeper structural work.
- Review wrapper must contain the full book object and exactly one full validated chapter.
- Quiz is mandatory at chapter gate and must contain 10 real questions with 3 choices each.
