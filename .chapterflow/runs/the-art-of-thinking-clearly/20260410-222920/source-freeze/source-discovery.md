# Source Discovery

## Objective

Freeze a lawful source bundle for *The Art of Thinking Clearly* before any chapter work.

## Discovery path

1. Checked for a public-domain full text. None found or expected for this modern commercial title.
2. Located an authorized Google Books entry for the HarperCollins edition. This provides stable metadata and a visible contents list.
3. Located the official Hodder & Stoughton title page for the English trade edition family.
4. Located Hachette's official PDF, *A Note on Sources*, which reproduces the chapter heading sequence with chapter-specific source notes.
5. Added secondary cross-check sources only to confirm chapter count and late-book continuity where preview access is thin.

## Working conclusion

The lawful source bundle for this run is:

- authorized Google Books metadata and contents
- official publisher edition page
- official publisher source-notes PDF
- narrow secondary cross-check references

No source-file request to the user was necessary.
