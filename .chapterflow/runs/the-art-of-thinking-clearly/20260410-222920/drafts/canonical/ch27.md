Something can start looking better the moment it becomes harder to get. A limited item, scarce opportunity, or narrowing window suddenly feels more important, more attractive, or more valuable than it did when access felt easy.

That is scarcity error. Rarity and urgency begin to inflate desire. A thing can seem worth more not because its quality changed, but because access tightened.

This is tempting because scarcity creates pressure. If the option may disappear, the mind can start treating that disappearance as proof that the option must matter. Limited access feels like a signal.

The trouble begins when availability gets mistaken for value. A team chases a narrow opportunity because it looks exclusive. A student wants a scarce spot partly because it is scarce. A person buys the limited version, rushes the reservation, or overvalues the hard-to-get experience because rarity has taken over the judgment. The problem is not that constraints never matter. The problem is letting scarcity certify quality on its own.

The practical correction is to remove the scarcity pressure mentally. Would this still look this good if it were easy to get? Would I still want it as much if it were abundant? Those questions pull value away from urgency.

The chapter does not ask for indifference to all limited opportunities. It asks for cleaner judgment: hard to get is not the same as worth getting. Better judgment tests desire after scarcity stops shouting.
