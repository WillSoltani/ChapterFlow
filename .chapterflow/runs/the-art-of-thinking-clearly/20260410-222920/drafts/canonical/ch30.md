The first number can quietly move the whole conversation. A price, target, score, or estimate appears early, and everything after it starts feeling high, low, fair, or absurd relative to that starting point.

That is anchoring. The initial figure sets a frame, and later judgment adjusts from it instead of beginning from scratch. Even an arbitrary number can push what feels plausible.

This is tempting because the first number gives the mind somewhere to stand. Once a reference point is present, later estimates often stay closer to it than they should. The starting figure becomes the range-setter.

The trouble begins when the anchor quietly defines reasonableness. A team accepts a budget range because the first figure made it seem normal. A student judges a score or estimate against the first number they heard. A buyer, seller, or negotiator reacts to the opening figure as if it were more informative than it really is. The problem is not that reference points never help. The problem is letting the first number do too much of the thinking.

The practical correction is to create an estimate before reacting to the anchor. What would this number look like if the first figure had never appeared? That question restores independence to the judgment.

The chapter does not ask for pretending anchors never exist. It asks for cleaner judgment: the first number is not automatically the right range. Better judgment builds a view before it lets the anchor set the frame.
