Core Claim:
Kahneman shows that preferences can reverse when options are compared jointly instead of separately. Evaluation mode changes what becomes salient and what looks better. The chapter matters because a preference that feels deep and stable can shift once the same options are seen under a different comparison structure. Its practical move is to compare the same options in more than one evaluation mode before trusting the first ranking as a fixed value judgment.

What Makes This Chapter Distinct:
Reversals sits between Keeping Score and Frames and Reality. It is the chapter that shows how preference itself can be unstable even when the options have not changed. Its distinctive value is that it reveals how separate evaluation and joint evaluation pull attention toward different features and can reverse the ordering of the same alternatives.

Author Logic Chain:
First Kahneman shows that evaluation mode changes which features dominate attention.
Then he shows that the same options can reverse rank when judged separately versus jointly.
Then he concludes that better judgment requires testing whether a preference survives changes in comparison frame.
