Core Claim:
Kahneman uses representativeness to show how stereotype fit can overpower base rates. A detailed description can feel diagnostic enough to hide the missing statistical context. The chapter matters because description quality can crowd out the prior odds that should anchor inference. Its practical move is to bring the base rates back into the judgment before letting the vivid profile carry the case.

Its distinctive value is that it turns a fast cue into a concrete audit point for later judgment errors.
