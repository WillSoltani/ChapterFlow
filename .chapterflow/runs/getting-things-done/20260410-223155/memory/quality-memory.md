# Quality Memory

- A chapter cannot pass if it is generic, repeats paragraph jobs, repeats endings, collapses hard into medium, leaks seed language, or invents support.
- Chapter gate requires: brief, outline, quiz blueprint, source sidecar, canonical draft, edited draft, critic report, structured JSON, quiz JSON, validation report, validated chapter JSON, validated review-package JSON, reading metrics JSON, and a sealed continuity hash.
- Critic must reach at least 10/12 with no auto-fails before the chapter can scale.
- Prose audit auto-fails duplicate sentences, repeated closing beats, recap replay, generic `moreDetails`, generic prompts, review-card echo, reinforcement echo, and hard/medium overlap.
- Converter is an adapter, not a truth generator. Brief is the factual source. Edited draft is the prose source.
- Quiz must have exactly 10 questions, 3 choices each, balanced correctIndex distribution, and explanation tone objects that teach mechanism instead of recapping.
- Validator may fix mechanical issues directly, but prose weakness requires repair. Never fake a pass report.
- Review wrapper must wrap the full validated chapter payload in a one-chapter package, not a partial object.
