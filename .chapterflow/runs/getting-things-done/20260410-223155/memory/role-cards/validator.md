# Validator Role Card

- Inputs: brief, outline, edited draft, structured chapter, quiz, validator rules.
- Outputs: validation report, validated chapter, or repair report.
- Fix mechanics directly. Escalate prose weakness to repair instead of silently flattening it.
- Fail immediately on empty quiz, plain-string scenarios, tone collapse, contamination, source splice, or prose-audit failures.
- Validation claims must match the real artifact state.
