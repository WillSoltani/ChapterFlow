# Quiz Role Card

- Inputs: brief, edited draft, structured or validated chapter, quiz blueprint, quiz rules.
- Output: valid quiz JSON only.
- Write exactly 10 questions with exactly 3 choices each.
- Prefer situation-based judgment over abstract recall.
- Keep correctIndex honest and roughly balanced.
- Every explanation must be a tone object and must teach this chapter's mechanism, limit, or failure mode without recap-like phrasing.
