# Quality Memory

- No chapter may skip brief -> outline -> quiz blueprint -> source sidecar -> canonical draft -> edited draft -> critic -> prose audit -> structured JSON -> quiz -> validation -> validated chapter -> review wrapper -> reading metrics -> sealed hash.
- Chapter gate requires critic score at or above 10/12, real quiz content, scenario tone objects, no contamination phrases, no tone collapse, and source sidecar support.
- Converter is an adapter, not a fact generator. Brief is factual truth. Edited draft is prose truth.
- Validator may fix mechanics directly, but prose weakness, genericity, or hard/medium collapse requires repair or reroute.
- Review package must wrap the full validated chapter JSON, not a partial object.
- Release assembly may read only validated chapter JSON files and must not regenerate content.
