Core Claim:
This chapter should argue that mission is not a free-floating preference. If meaningful work depends on a focused mission, that mission also depends on earlier capital. Newport's logic should stay continuous with the rest of the book: rare and valuable skills create the leverage, credibility, and room that make a real mission more than aspiration.

What Makes This Chapter Distinct:
This is the first hard requirement chapter for Rule 4. It turns mission from an attractive direction into something that must rest on prior career capital.

Author Logic Chain:
First the author reframes mission as something that needs support rather than mere sincerity.
Then the author links mission to scarce skills and earlier capital.
Then the author concludes that meaningful direction becomes actionable only when prior development makes it possible.
