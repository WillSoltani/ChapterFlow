# Style Memory

- Write like a sharp human explainer with taste: concrete, specific, readable, and authored.
- Prioritize strong openings, distinct paragraph jobs, vivid applications, and honest limits.
- Reader-facing prose should teach the idea directly, not narrate the chapter or sound like planning notes.
- Easy must feel accessible, medium must explain mechanism and use, hard must add a real limit or threshold question.
- If a sentence sounds generic, pre-manufactured, faux-profound, or smarter than the brief supports, cut it.
- Avoid thesis-first openings, repeated sentence skeletons, fake mechanism language, and chapter-generic life coaching.
- Never leak brief, outline, validator, or seed language into reader-facing prose.
- No em dashes. No invented studies, quotes, neuroscience, or prestige filler.
