# Quality Memory

- Source-of-truth order: brief, outline, edited draft, structure rules, quiz blueprint, validation rules.
- No chapter may skip brief -> outline -> quiz blueprint -> source sidecar -> writer -> editor -> critic -> prose decision -> converter -> quiz -> validator.
- Canonical and edited drafts must be real prose, not pseudo-structured depth blocks.
- Every paragraph must do a distinct job and the prose must feel unmistakably about the active chapter.
- Hard depth must preserve a live tension or boundary, not restate medium with longer wording.
- Flagship mode requires tone objects for scenario, whatToDo, and whyItMatters.
- Chapter gate fails on contamination phrases, plain-string scenarios, empty quiz in generate mode, identical tone objects, source-splice leakage, or unsupported detail.
- Review package must wrap the full validated chapter JSON as a one-chapter `chapters` array.
- Patch only local defects. If weakness is global, reroute through writer or editor before structure.
