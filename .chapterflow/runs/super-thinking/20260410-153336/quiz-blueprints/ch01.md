# Quiz Blueprint

- chapterId: ch01
- chapterTitle: Being Wrong Less

## Core skills to test
1. Distinguishing self-inflicted mistakes from outside shocks
2. Recognizing when first-principles reasoning is needed
3. Separating useful stress from destructive fragility
4. Choosing de-risking or MVP-style testing before commitment

## Question distribution targets
- q01-q03: identify avoidable error vs bad luck
- q04-q06: apply first-principles reasoning in concrete situations
- q07-q08: diagnose when bounded stress can teach versus when it only harms
- q09-q10: synthesize wrong-less thinking with low-cost experimentation

## Scenario pool
- Work: a manager launches a feature without checking the core assumption
- School: a student repeats polished arguments without checking the foundation
- Personal: someone escalates a high-cost purchase before a cheap test
- Sport/performance: repeat the tennis unforced-error logic in another domain

## Distractor rules
- Tempt the reader with confidence, speed, or overplanning
- Avoid joke answers and obvious straw men
- Wrong answers should fail because they ignore assumptions, downside, or the difference between learning stress and reckless exposure
