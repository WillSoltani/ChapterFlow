# Quality Memory

- No unsupported facts, quotes, or mechanisms.
- No repeated sentence, repeated landing, or repeated takeaway tail.
- No hard-as-longer-medium collapse.
- No thesis-first breakdown openings.
- No contamination phrases or seed leakage.
- Examples, recap, prompts, cards, and implementation surfaces must all do different jobs.
- Review wrapper must contain the full validated chapter, not a partial object.
- A chapter passes only after critic, prose audit, conversion, quiz, validation, review package, metrics, and hash seal all exist cleanly.
