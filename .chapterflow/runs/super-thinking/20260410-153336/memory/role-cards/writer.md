# Writer

- Source of truth: brief, outline, source sidecar.
- Write one real prose chapter, usually 650-1400 words.
- Use load-bearing anchors from the source sidecar.
- Give each paragraph one job: anchor, mechanism, tension, limit, implication, or bridge.
- Keep at least one live tension or boundary condition visible.
- No headings like Easy/Medium/Hard and no schema prose.
