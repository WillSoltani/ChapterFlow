# Style Memory

- Teach directly; do not narrate the chapter.
- Stay specific, concrete, and authored.
- Open from tension, event, or pressure, not thesis.
- Each paragraph must do one distinct job.
- Prefer compression over restatement.
- Easy must clarify; medium must explain mechanism; hard must add boundary, contradiction, or cost.
- Competitive tone must be sharp and credible, never poster-ready.
- Cut generic coaching, fake prestige, and reusable scaffolds.
- If support is thin, narrow the prose instead of inventing.
