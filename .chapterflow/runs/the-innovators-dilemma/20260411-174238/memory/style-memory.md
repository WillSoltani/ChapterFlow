# Style Memory

- Teach the idea, not the existence of the chapter.
- Prefer concrete industry pressure over abstract management slogans.
- Start from tension, failure, or conflict rather than thesis-first summary.
- Keep paragraphs distinct: anchor, mechanism, tension, limit, implication, bridge.
- Stay sharp and readable. Avoid textbook tone, helper-model polish, fake profundity, and corporate filler.
- Competitive tone must stay credible and concise, not theatrical.
- If source support is thin, narrow the claim instead of inventing detail.
