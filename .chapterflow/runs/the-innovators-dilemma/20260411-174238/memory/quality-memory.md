# Quality Memory

- No invented facts, quotes, case details, or mechanisms beyond the brief and source sidecar.
- No repeated sentence, repeated ending beat, or duplicated paragraph job.
- Easy must stay simple. Medium must explain mechanism and application. Hard must preserve a live limit or threshold question.
- Support surfaces must do different jobs: takeaway, recap, card, prompt, implementation.
- Review wrapper must contain the full validated chapter JSON as its single chapter payload.
- Stay paraphrase-first because the frozen source is partial.
