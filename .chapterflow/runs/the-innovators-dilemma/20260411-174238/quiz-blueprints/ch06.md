# Chapter Quiz Blueprint

Chapter: Give Responsibility for Disruptive Technologies to Organizations Whose Customers Need Them
Core concepts to test:
- responsibility should sit with the unit whose customers need the disruptive technology
- customer pull shapes priorities inside an organization
- the wrong organizational home can create rational neglect
- autonomy can matter because it changes which customers define success
- the rule is about placement, not a universal command to split everything apart

Bloom ceiling:
- highest justified level for this chapter: evaluate

Question plan:
- q01: identify the chapter's placement rule
- q02: define why customer pull matters
- q03: apply the wrong-home problem
- q04: named work scenario about moving ownership
- q05: distinguish executive intent from customer-fit reality
- q06: reject the misreading that all disruption needs full separation
- q07: school transfer about the right team owning a beginner tool
- q08: personal scenario about burying a project in the wrong backlog
- q09: deeper synthesis on rational neglect inside the wrong unit
- q10: bridge toward Chapter 7's market-size fit problem

Distractor notes:
- tempting wrong answer type 1: leadership support alone fixes the issue
- tempting wrong answer type 2: every disruptive effort requires a standalone company

Explanation diversity notes:
- avoid repeated openers
- each direct explanation must begin differently

CorrectIndex plan:
- keep distribution roughly balanced across 0 / 1 / 2
