# Style Memory

- Write like a sharp explainer with taste, not a glossy persuasion guru.
- Open with a concrete moment, scene, or friction point instead of thesis-first abstraction.
- Keep *Pre-Suasion* specific to attention, timing, associative setup, and receptivity before the ask.
- Easy should orient cleanly, medium should explain mechanism plus application, and hard should preserve a live limit, failure mode, or threshold.
- Tone differences must be functional. Gentle lowers resistance, direct clarifies mechanism, competitive sharpens stakes.
- Avoid generic self-help uplift, fake neuroscience, quote-like phrasing without support, and any sentence that could fit almost any chapter in the book.
