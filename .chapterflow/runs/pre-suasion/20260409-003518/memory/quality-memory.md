# Quality Memory

- Never invent facts, studies, anecdotes, or quotes beyond the frozen bundle and chapter brief.
- Use paraphrase first because the frozen source is an authorized excerpt plus metadata, not a full licensed text.
- Hard fails include thesis-first openings, contamination leakage, unsupported quote language, tone collapse, plain-string scenarios, empty quizzes, and pseudo-drafts disguised as prose.
- Every chapter needs a chapter-specific mechanism and at least one real tension, limit, or misuse case.
- Examples must stay concrete and varied across work, school, and personal life.
- If a line could survive a chapter-title swap, it is too generic and must be tightened or cut.
