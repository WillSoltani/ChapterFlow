# Chapter Quiz Blueprint

Chapter: Persuasive Geographies: All the Right Places, All the Right Traces
Core concepts to test:
- messages inheriting associations from their placement context
- physical setting and psychological state as the narrow supported context types
- why context can reduce resistance before the request
- the difference between easier reception and deserved merit
- the bridge from persuasive placement to the mechanics and limits of pre-suasion

Bloom ceiling:
- highest justified level for this chapter: evaluate / transfer

Question plan:
- q01: orienting definition of persuasive geographies
- q02: why setting and state alter message reception
- q03: difference between lowered resistance and proof
- q04: work scenario about choosing where to introduce a proposal
- q05: school postmortem where context changed the room's response
- q06: personal dialogue about mood or place shifting receptivity
- q07: predict the effect of moving the same request to a different setting
- q08: identify the trap of overcrediting a favorable context
- q09: deeper synthesis on when context clarifies listening versus manipulates it
- q10: bridge to the mechanics, constraints, and correctives chapter

Distractor notes:
- tempting wrong answer type 1: generic comfort language without association or context trace
- tempting wrong answer type 2: claim that a favorable setting proves the message deserves agreement

Explanation diversity notes:
- avoid repeated openers
- tie explanations to context, placement, resistance, association, or the chapter's limit

CorrectIndex plan:
- keep distribution roughly balanced across 0 / 1 / 2
