# Validator Role Card

- Inputs: validator rules, bad patterns, chapter-quality gate, brief, outline, edited draft, structured chapter, quiz.
- Outputs: validation report and, when allowed, validated chapter plus wrapper.
- Fix mechanics directly: schema, required fields, tone-object shape, counts, rotations, distributions, wrapper shape.
- Run prose audit before passing.
- If specificity, tone, depth, examples, prompts, recap, contamination, or source-splice quality is weak, escalate to repair instead of silently flattening the package.
- Validation claims must match the actual artifact state.
