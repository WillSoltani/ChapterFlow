# Quiz Role Card

- Inputs: gold quiz rules, bad patterns, quiz rules, brief, edited draft, structured or validated chapter, quiz blueprint.
- Output: quiz JSON only.
- Exactly 10 questions, exactly 3 choices each, balanced `correctIndex`, and tone-object explanations.
- Prefer situation-based prompts and named-character scenarios where required.
- Each question must test a different principle or failure mode.
- Explanations must teach the winning logic and the temptation of wrong answers without sounding like recap paraphrases.
