## Result

- dominant working edition locked automatically: 2018 Random House Publishing Group U.S. release family
- source basis: authorized publisher metadata and description, Google Books limited preview contents, library catalog contents, and Taleb-authored Medium excerpts from the book
- user clarification not required: no material edition, abridgment, or translation ambiguity was found at chapter-map level

2. Penguin Random House exposes publisher-controlled metadata across hardcover, ebook, audiobook, and later paperback formats.
3. Richland Library exposes a fuller contents listing that resolves the major chapter map beyond the truncated Google Books contents.
4. Taleb's INCERTO Medium publication contains multiple chapter-labeled excerpts, providing authorized partial text support for several chapters.

## Freeze boundary

The run will treat the following as frozen and authorized for research-native chapter generation:

- chapter order and naming from the locked edition family
- publisher description and metadata
- verified partial text only where Taleb published excerpts under INCERTO on Medium
- narrow secondary interpretation only where needed and only when consistent with the frozen chapter map

## Restrictions carried forward

- exact quotations are allowed only when directly supported by the frozen authorized preview or excerpt set
- unsupported details must be paraphrased narrowly or excluded
- no chapter work may begin from unstated memory or speculative reconstruction
