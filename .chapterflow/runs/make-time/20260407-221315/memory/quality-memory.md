# Quality Memory

- Do not invent facts beyond the brief and frozen source bundle.
- If source support is thin, stay narrow and paraphrastic.
- Easy must clarify, medium must explain and apply, hard must deepen with tension.
- Examples must feel specific, not polished copies of each other.
- Implementation advice must be chapter-specific.
- Quiz questions must test distinct principles and use tempting distractors.
- Watch for tone collapse, repeated argument loops, and thesis-first openings.
