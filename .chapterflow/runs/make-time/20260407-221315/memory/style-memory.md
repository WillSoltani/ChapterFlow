# Style Memory

- Write like a sharp explainer, not a productivity preacher.
- Open on tension, scene, or friction, not thesis.
- Keep paragraphs distinct in job and movement.
- Prefer concrete details over generic self-help phrasing.
- Tone must differ by function:
  - gentle lowers resistance
  - direct names the mechanism cleanly
  - competitive frames stakes and leverage without turning cartoonish
- Hard depth must add a real limit, tradeoff, or failure mode.
- Avoid fake authority, generic recap language, and filler mechanism talk.
