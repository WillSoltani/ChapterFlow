## Official Framework Support

The official Make Time site describes the book as a friendly framework for focus and energy built around:

- `Highlight`: choose a priority for the day
- `Laser`: beat distraction
- `Energize`: use the body to recharge the brain
- `Reflect`: note what worked, what did not, and what to try tomorrow

- Busy Bandwagon
