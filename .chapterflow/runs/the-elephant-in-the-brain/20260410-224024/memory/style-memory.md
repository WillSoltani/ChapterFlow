# Style Memory

- Explain with pressure, specificity, and concrete anchors.
- Keep the prose authored, sharp, and narrower than the evidence when support is thin.
- Avoid thesis-first openings in reader-facing content.
- No fake depth, filler mechanism language, or inflated abstraction.
- Easy should open the door cleanly, medium should explain mechanism, hard should preserve a live tension.
- Do not narrate "the chapter" when direct teaching would work better.
