# Style Memory

- Write like a calm, sharp explainer, not a finance preacher.
- Start on friction, contrast, or risk, not an abstract thesis.
- Keep prose concrete and behavior-first.
- Gentle lowers resistance, direct names the mechanism, competitive frames stakes without cartoon aggression.
- Hard depth must add a real limit, tradeoff, or failure mode.
- Avoid unsupported quotation, status jargon, fake authority, and filler recap language.
