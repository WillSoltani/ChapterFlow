# CH06 Outline

## Hook

- Open on the fact that building and keeping are different games.
- Show why success can be lost by using accumulation instincts in a preservation phase.

## Build

- Contrast bold accumulation with durable survival.
- Explain room for error as practical design, not fear.
- Show humility and caution as tools that protect compounding.
- Emphasize that ruin ends the game even if the upside case looked attractive.

## Deliver

- Land survival as the highest rule once wealth exists.
- Show preservation as a separate skill worthy of respect.
- Make avoiding total failure more important than maximizing every gain.

## Bridge

- Connect survival to a world where only a few large wins matter.
- Open the next chapter by showing how many misses can be tolerated if the game stays alive.

## Distinct Scenario Lesson Map

1. Work / decision_point:
   reject a concentrated bet that threatens long-run durability
2. School / postmortem:
   review how overconfidence turned a good streak into avoidable damage
3. Personal / dialogue:
   compare building wealth with protecting it inside a household plan
4. Work / predict_reveal:
   uncover that the resilient operator kept more margin than the flashy one
5. School / dilemma:
   choose between max upside and staying in the game
6. Personal / before_after:
   reframe smart money from aggressive growth to durable continuation

## Takeaway Count Lock

- Easy: 3
- Medium: 5
- Hard: 6

## Implementation Plan Direction

- Core skill: protect survival
- Work plan: keep room for error when outcomes are flattering
- School plan: learn to separate a strong streak from permanent invulnerability
- Personal plan: define which risks would end the game and avoid them
