# Style Memory

- Write like a sharp human explainer with taste.
- Specific over generic. Concrete over abstract. Insight over padding.
- Open on live tension, not a thesis announcement.
- Paragraph jobs must be visibly distinct.
- Use vivid anchor material and honest limits.
- If a sentence sounds pre-manufactured, podcast-summary generic, or smarter than the brief, cut it.
- No em dashes. No filler prestige language. No fake profundity.
