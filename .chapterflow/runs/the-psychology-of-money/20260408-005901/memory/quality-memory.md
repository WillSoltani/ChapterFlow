# Quality Memory

- Freeze sources before chapter writing.
- No bulk generation. No one-pass synthesis. No script-authored reader-facing content.
- Brief is factual truth. Edited draft is prose truth. Converter adapts, not invents.

- Scenario fields must be tone objects in required mode.
- Hard depth must add a real limit, failure mode, or unresolved tension, not just extra length.
