# CH01 Quiz Blueprint

Goal: test whether the reader can apply the opening frame rather than merely repeat it.

Coverage:
- 2 recall questions on the opening contrast and core claim
- 3 understanding questions on behavior versus knowledge
- 3 application questions using work, school, and personal scenes
- 2 analysis questions on limits, misreadings, and the bridge to Chapter 2

Required reminders:
- use only chapter-supported facts
- explanations should restate the chapter's logic, not generic study advice
- include at least one question that checks the math-versus-behavior limit condition
