# Quality Memory

- No chapter converts until prose clears the critic gate.
- Required chapter-gate floor: critic score at least 10/12 and no auto-fails.
- Source sidecar must exist before writer work and must match the frozen source bundle.
- Scenario, whatToDo, and whyItMatters must all be tone objects in flagship mode.
- Quiz cannot be empty in chapter-gate mode.
- Hard depth must add a real limit, failure mode, contradiction, or threshold question instead of stretching medium.
- Review package must wrap exactly one full validated chapter payload.
- Validation reports must match the actual lint and artifact state.
