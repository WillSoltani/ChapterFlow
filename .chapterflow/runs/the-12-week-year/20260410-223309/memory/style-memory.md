# Style Memory

- Teach the execution idea directly rather than narrating the artifact.
- Stay concrete, specific, and operational. Avoid motivational fog and generic productivity slogans.
- Paraphrase first. Use only source-supported terms and claims from the frozen bundle.
- Easy must open from a recognizable pressure point and stay readable. Medium must explain mechanism plus application. Hard must preserve a real limit or threshold question.
- Tone differences must be functional, not adjective swaps.
- Keep implementation surfaces chapter-specific and avoid generic consistency coaching.
