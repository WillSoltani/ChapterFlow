# Introduction Quiz Blueprint

- What is deep work in the introduction's terms?
- What does the introduction call shallow work?
- Why does the introduction say deep work matters?
- What tension does the introduction set up?
- How does the introduction want the reader to judge a day?
- Why is shallow work described as dangerous when it dominates the schedule?
- Which example best fits the introduction's idea of deep work?
- What does the introduction say about shallow work itself?
- Why is naming deep and shallow work already useful before any rule appears?
- If someone feels busy all day but finishes no demanding work, how would the introduction interpret that day?
