# Introduction

## Core Sections
1. The book starts by separating concentrated value-creating effort from reactive logistical effort.
2. The introduction links depth to rapid skill acquisition and high-quality production.
3. The problem is not that shallow work exists. The problem is when it crowds out the work that matters most.
4. The introduction sets up a mismatch between what the economy values and what daily norms reinforce.
5. The first operational shift is diagnostic: ask whether real focus had room to happen.
