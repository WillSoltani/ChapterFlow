# Quality Memory

- Never invent facts, studies, examples, or quotes beyond the frozen bundle and chapter brief.
- Use paraphrase first because the source base is official-summary-plus-excerpts plus secondary chapter support, not a full licensed text.
- Hard fails include thesis-first openings, contamination leakage, unsupported quote language, tone collapse, plain-string scenarios, empty quizzes, source-splice leakage, and pseudo-drafts masquerading as prose.
- Every chapter needs a chapter-specific mechanism plus at least one real limit, tension, or failure mode.
- Scenarios must stay concrete and distinct across work, school, and personal contexts.
- If a sentence could fit several chapters just by swapping titles, it is still too generic.
