# Style Memory

- Write like a sharp human explainer, not a motivational-content generator.
- Open with a scene, tension, or friction point instead of a thesis sentence.
- Keep Atomic Habits specific to Clear's mechanics: compounding, systems, identity, the habit loop, the Four Laws, friction, tracking, accountability, and deliberate refinement.
- Easy should orient cleanly, medium should explain the mechanism, and hard should keep a real limit, tradeoff, failure mode, or threshold question alive.
- Tone differences must change function, not just intensity.
- Avoid generic self-help uplift, fake neuroscience, and any detail the frozen bundle cannot support.
