# Style Memory

- Write like a sharp human explainer with taste.
- Specific over generic. Concrete over abstract. Compression over restatement.
- Open from pressure, event, conflict, or a live question. Never thesis-first.
- Keep paragraph jobs distinct: anchor, mechanism, tension, limit, implication, bridge.
- Easy: grade 8-9, pictureable opening, one clean model, one practical implication.
- Medium: grade 10-11, explain mechanism plus application, no paraphrase padding.
- Hard: grade 12, add threshold question plus at least two of boundary, contradiction, cost, hidden structure, synthesis, failure mode.
- Tones differ in function, not adjective swaps.
- Competitive tone stays severe and credible, never theatrical.
- Reader-facing content should almost never talk about "the chapter."
- If a sentence sounds premade, podcast-summary generic, or smarter than the brief supports, cut it.
- Reject reusable scaffolds like "The real issue is" or "What matters is."
- No contamination phrases, no pseudo-science filler, no motivational-poster endings.
