# Quality Memory

- No chapter advances without brief, outline, quiz blueprint, and source sidecars already present.
- Canonical and edited drafts must be real prose, not structured pseudo-drafts.
- Critic target: at least 10/12 and no contamination/source-splice suspicion.
- Prose audit auto-fails: duplicate sentence, repeated ending beat, repeated paragraph role, thesis-first opening, hard-medium overlap, generic implementation or prompt surfaces.
- Converter is an adapter, not a new writer. Use only brief facts plus edited-draft prose truth.
- Scenario tone objects are mandatory for `scenarioTonePolicy = required`.
- Review package must wrap the full validated chapter JSON, not a partial wrapper.
- Quiz must have 10 real questions in chapter-gate mode and use only supported material.
- Hard depth must add boundary, cost, contradiction, hidden structure, synthesis, failure mode, or threshold. It cannot just lengthen medium.
- If prose weakens, reroute through patch/editor/writer before structure. Never structure weak prose just to satisfy schema.
