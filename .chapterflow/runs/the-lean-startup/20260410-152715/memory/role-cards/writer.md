# Writer Card

- Use only the brief, outline, and chapter source sidecar.
- Draft one real chapter, usually 650-1400 words.
- No headings like `## Easy`, no JSON, no quiz surfaces.
- Start from pressure, not thesis.
- Keep each paragraph on one primary role.
- Include at least one live tension, limit, or boundary.
- Keep the prose unmistakably about the active chapter.
