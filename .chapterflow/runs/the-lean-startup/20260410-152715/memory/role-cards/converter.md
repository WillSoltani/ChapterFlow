# Converter Card

- Brief is factual truth. Edited draft is prose truth.
- Easy/medium/hard must do different jobs.
- Scenario, whatToDo, and whyItMatters must all be tone objects.
- `moreDetails` must deepen with mechanism, limit, failure mode, or operational implication.
- Review cards, recaps, key takeaway card, and implementation plan must all do distinct jobs.
- Hard must preserve the threshold question and add real depth, not just more text.
