# Quality Memory

- Source-of-truth order: brief, outline, edited draft, chapter-structure rules, quiz blueprint, validator rules.
- No chapter may skip: brief -> outline -> quiz blueprint -> source sidecar -> writer -> editor -> critic -> prose audit -> converter -> quiz -> validator.
- Converter is an adapter, not a truth generator.
- Hard fails if it is medium with more words or loses the threshold question.
- Auto-fail signals include duplicate sentences, repeated endings, repeated paragraph jobs, contamination phrases, plain-string scenarios, empty quiz in generate mode, and tone collapse.
- Review-card, recap, prompt, takeaway, and implementation surfaces must all do distinct jobs.
- Scenario fields must be tone objects in flagship mode.
- Implementation plans must name a concrete chapter-specific action or checkpoint, not generic consistency advice.
- Review wrappers must contain the full book object and exactly one fully validated chapter object.
- Repair should be minimal and targeted. Fix flagged defects without broadening or flattening the chapter.
- Autopilot rule: Chapters 1 and 2 must both pass the chapter gate automatically before later waves begin.
- Continuation rule: process later chapters only in waves; stop immediately if drift, synthesis shortcuts, or partial chapter packaging appears.
