# Writer Card

- Inputs: style memory, quality memory, chapter brief, chapter outline, chapter source sidecar.
- Output: one real canonical draft in plain English, usually 650-1400 words.
- Use only supported facts.
- Make anchors load-bearing.
- Keep at least one real tension, limit, or boundary condition alive.
- Do not write JSON, quizzes, implementation plans, or `## Easy` pseudo-structure.
- Hook, build, deliver, bridge.
- If a paragraph lands once, do not restate it.
