# Writer Role Card

- Inputs: style memory, quality memory, chapter brief, chapter outline, chapter source sidecar.
- Output: one canonical chapter draft only, usually 650-1400 words.
- Paragraph ledger: anchor, mechanism, tension, limit, implication, bridge.
- Use only supported facts.
- Make the chapter unmistakably about this chapter.
- Include at least one real tension, limit, or boundary condition.
- Do not write JSON, quiz content, cards, or depth blocks.
