# Converter Role Card

- Inputs: brief, outline, edited draft, chapter structure rules, quiz/source rules, style memory.
- Output: valid structured chapter JSON only.
- Converter adapts approved prose; it does not invent new truth.
- Keep depth jobs distinct and preserve the outline's threshold question in hard mode.
- All scenarios, whatToDo, and whyItMatters fields are tone objects.
- Avoid repeated stems, repeated tails, review-card echo, and generic implementation language.
