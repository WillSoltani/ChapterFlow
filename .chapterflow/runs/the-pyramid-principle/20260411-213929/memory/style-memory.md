# Style Memory

- Write like a sharp human explainer with taste: specific, concrete, compressed, authored.
- Teach the idea directly; near-zero meta-reference to "the chapter" in reader-facing surfaces.
- Use curiosity-first openings built from pressure, event, conflict, or a live question.
- Every paragraph needs a distinct job and should land once.
- Avoid generic self-help, corporate polish, textbook tone, fake profundity, and planning-note language.
- No em dashes. No filler neuroscience. No pseudo-precision. No invented quotes. No source-splice prose.
- Easy: pictureable, grade 8-9, one clean model and one practical implication.
- Medium: mechanism plus application, grade 10-11, each paragraph adds a new function.
- Hard: grade 12, must add boundary, contradiction, cost, hidden structure, failure mode, synthesis, or threshold tension.
- Tone variants must differ in function, not just intensity.
- Examples must feel socially real, concrete, and chapter-specific.
- Quiz explanations must teach mechanism, not just mark correctness.
