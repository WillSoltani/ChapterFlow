# Quality Memory

- Do not invent facts beyond the brief and source sidecar.
- Reject generic chapters that could fit elsewhere in the book.
- Reject thesis-first openings, repeated paragraph jobs, repeated endings, and medium-hard collapse.
- Anchors must be load-bearing when the brief supports them.
- Support surfaces must do distinct jobs:
  - key takeaway card distills
  - review cards retrieve
  - recap.retrieve tests recall
  - recap.connect ties mechanism to consequence
  - recap.preview asks for prediction
  - moreDetails deepen rather than restate
  - implementation plan names chapter-specific action and friction
- Scenario fields must be tone objects in flagship mode.
- Empty quiz, identical tones, contamination phrases, or unsupported source splices are immediate fails.
- Validator may fix mechanics directly, but prose weakness must escalate to repair rather than being flattened silently.
