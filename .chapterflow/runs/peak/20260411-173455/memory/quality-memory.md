# Quality Memory

- Hard fail on invented facts, source-splice leakage, contamination phrases, empty quiz, plain-string scenarios, or identical tone objects.
- Critic threshold is `10/12` minimum before conversion.
- Prose audit rejects repeated sentence reuse, repeated endings, paragraph-role duplication, generic moreDetails, generic prompts, generic implementation plans, and hard-medium overlap.
- Review package must wrap exactly one full validated chapter payload and match that payload exactly.
- Source sidecars must exist before writer work and must derive from the frozen bundle.
- Release assembly may read validated chapter JSON only. No regeneration during release.
