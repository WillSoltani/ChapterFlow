# Quality Memory — Difficult Conversations v12 Run

## Chapter Quality Gate (12-point rubric, need ≥10/12)

### 6 Scored Categories (0/1/2 each)
1. **Chapter Specificity** — could it fit another chapter? (2 = unmistakably this chapter)
2. **Anchor Use** — are anchors load-bearing or decorative? (2 = anchors carry the thinking)
3. **Analytical Value** — real mechanism/distinction/tension? (2 = gives reader real tool)
4. **Paragraph Motion** — distinct jobs, no repetition? (2 = every paragraph earns its place)
5. **Prose Quality** — sharp, vivid, authored? (2 = not templated, padded, or flat)
6. **Hook and Bridge** — opening pulls, ending opens next question? (2 = both work)

### Auto-Fail Conditions (any one → reject immediately)
- Invented facts, quotes, studies, mechanisms, anecdotes
- Generic enough to fit another chapter
- Paragraph-job repetition
- Hard depth = medium made longer
- Pseudo-science, filler neuroscience, fake precision
- Moral complexity framed as endorsement rather than strategic awareness
- First sentence is thesis-first (not curiosity-first)
- Contamination leakage (brief/outline/seed language in reader-facing content)
- Identical tone collapse in required learning surfaces
- Source splice leakage

### Required Craft Checks (before scoring)
- First sentence creates curiosity, not thesis
- At least 2 strong anchors from brief used
- Real tension, limit, or failure mode present
- Readable, concrete, not inflated
- Ending opens a next question (does not flatten to summary)
- At least one genuinely memorable line every 200-300 words

## Hard Depth Rules
Hard must add at least one of:
- Genuine boundary condition
- Failure mode
- Threshold question (must stay alive, not resolved)
- Contradiction
- Unresolved tension
- Synthesis across concepts

Hard fails if: medium with more words / sharpest tension from brief disappears / turns into book report / inflates vocabulary instead of deepening thought

## Readability Rules
- Easy: pictureable situation in first 2 sentences, short/medium sentences, concrete nouns first, no stacked abstractions
- Medium: mechanism plus application
- Hard: cognitive load high but readable, add tension/limit/synthesis/threshold
- Preview: must ask or imply real prediction (not explain next chapter fully)
- Recap retrieve: recall challenge, not summary

## Evidence Anchor Rules
For every required anchor:
- Include named person/place/event when source supports it
- Include concrete detail
- Include friction or turning point
- Include consequence
- Note quote status if exact line is allowed
- Anchors must be load-bearing, not decorative

## Validator Pass Criteria
- Valid JSON
- Required fields present
- Tone objects where required
- Word counts within range
- Example schema valid
- Quiz schema valid
- Format rotation, endingType rotation correct
- 2/2/2 category distribution
- Passage of prose checks
- No contamination phrases in reader-facing content
