# Style Memory

- Teach the idea directly; avoid talking about "the chapter."
- Start from pressure, scene, or live tension, not a thesis announcement.
- Keep prose concrete, authored, and compressed.
- No em dashes, filler abstraction, slogan tails, fake neuroscience, or generic coaching language.
- Easy clarifies; medium explains mechanism and application; hard adds boundary, contradiction, failure mode, or synthesis.
- Tone differences must be functional, not adjective swaps.
- Every paragraph should do one primary job and land once.
