# Chapter Outline

## Opening
- Ariely opens the chapter by showing that ownership changes price in the owner's mind before the object changes in reality.

## Core Moves
- The endowment effect makes owned items feel more valuable than unowned items.
- Sellers ask much more than buyers offer because loss hurts more than equivalent gain feels good.
- Effort and imagined possession can create similar inflation.
- Ownership distorts exchange because people stop valuing the object from a neutral starting point.
- The practical answer is to price from the outside by asking what you would pay today if it were not already yours.
