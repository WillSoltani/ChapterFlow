# Quality Memory

- Every chapter must validate as sealed `1.1.0` EMH content with 6 canonical examples, 10 quiz questions, 5 review cards, and a real implementation plan.
- Scenario, whatToDo, whyItMatters, recap surfaces, and quiz explanations stay as tone objects with materially distinct variants.
- The chapter loop is not complete until the critic report, validation report, quiz artifact, review package, and validated chapter file all exist.
- Use chapter-specific experiments and tensions; do not let any chapter read like "behavioral economics in general."
- If coverage is thinner on a later chapter, narrow the claim surface rather than inflating certainty.
