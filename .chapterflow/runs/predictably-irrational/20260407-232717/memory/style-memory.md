# Style Memory

- Write like a sharp explainer, not a pack narrator: concrete, readable, chapter-bound, and willing to admit a real limit.
- Start from a live experiment, scene, or decision trap instead of a thesis announcement.
- Easy should clarify the move, medium should explain the mechanism, and hard should preserve the edge or unresolved tension.
- Tone differences must be functional: gentle lowers friction, direct sharpens the mechanism, competitive raises the stakes without turning hostile.
- Keep chapter language specific to Ariely's experiments and avoid generic self-help wrappers, fake profundity, and repeated sentence skeletons.
