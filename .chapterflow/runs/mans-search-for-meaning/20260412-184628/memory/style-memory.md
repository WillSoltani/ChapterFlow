# Style Memory

- Teach the idea directly; avoid narrating the chapter.
- Stay concrete, specific, and compressed.
- Open from pressure, event, bodily stake, or live tension, not thesis summary.
- Every paragraph needs one main job and one landing.
- No filler neuroscience, fake precision, or generic uplift.
- If the source is thin, stay narrow instead of inventing depth.
- Easy should orient cleanly; medium should explain mechanism and use; hard should add limit, contradiction, threshold, or synthesis.
- Tone variants must differ in function, not by adjective swap.
- Support surfaces must not echo each other.
- Competitive tone must be severe and credible, never poster-ready.
- Memoir-rooted material must keep event, body, cost, and psychological pressure visible.
