# Quality Memory

- Auto-fail invented facts, unsupported quotes, contamination phrases, thesis-first openings, hard-medium collapse, and duplicate sentences.
- Chapter specificity matters more than breadth.
- Use at least two load-bearing anchors when available.
- Medium and hard must do materially different cognitive work.
- `moreDetails` must deepen, not restate.
- Review cards, recap, prompts, and implementation plan all need distinct jobs.
- Scenario tone objects are mandatory.
- Empty quiz in generate mode is an immediate fail.
- Review wrapper must contain the full validated chapter payload, not a partial chapter object.
- Seal chapter hashes only after validation passes and artifacts are complete on disk.
