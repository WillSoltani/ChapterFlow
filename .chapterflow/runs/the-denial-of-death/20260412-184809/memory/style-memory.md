# Style Memory

- Write like a sharp human explainer with taste.
- Prefer specificity, concreteness, and real analytical value over abstraction or padding.
- Start from pressure, event, tension, or a live question, not a thesis announcement.
- Keep paragraph jobs distinct: anchor, mechanism, tension, limit, implication, bridge.
- Teach the idea directly; references to "the chapter" should be near-zero in reader-facing prose.
- Use strong openings and endings that open the next question instead of flattening into summary.
- Easy must clarify; medium must explain mechanism and application; hard must add limit, contradiction, boundary, cost, or synthesis.
- Competitive tone must stay severe and credible, never poster-ready or theatrical.
- Cut generic self-help, corporate phrasing, textbook tone, fake profundity, and sentence skeleton reuse.
- If a sentence sounds pre-manufactured, smarter than the brief, or like a note to the writer, delete it.
