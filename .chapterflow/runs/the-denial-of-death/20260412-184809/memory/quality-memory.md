# Quality Memory

- No downstream invention beyond the brief and frozen source bundle.
- No exact repeated sentence anywhere in the chapter package unless structurally required.
- No thesis-first or slogan-first openings.
- No repeated paragraph landing, repeated ending beat, or repeated template tail across takeaways, cards, recap, prompts, or implementation surfaces.
- Hard depth must do different cognitive work than medium, not longer paraphrase.
- `moreDetails` must add mechanism, limit, failure mode, cost, contradiction, synthesis, or operational implication.
- Support surfaces must do different jobs: takeaway card distills, review cards retrieve, recap compresses or tests, implementation names a concrete action, prompts provoke a chapter-specific move.
- Scenario fields must be tone objects in flagship mode.
- Chapter gate requires critic score at or above 10/12, source sidecar integrity, non-empty quiz in generate mode, and zero auto-fail prose issues.
- Review-package must wrap the full validated chapter JSON exactly.
