# Source Freeze Report

## Frozen bundle

- `book-source.txt`: complete frozen Project Gutenberg George Long translation
- `toc.json`: canonical twelve-book order for the locked working edition
- `sidecars/source/source-heading-index.json`: chapter heading index for chapter-local sidecars
- `manifests/source-ledger.json`: full source ledger
- `manifests/edition-lock.json`: edition decision and rationale

## Authority order for chapter work

1. Frozen George Long primary text
2. Frozen heading index and TOC derived from that text
3. Cross-check notes from the alternate Project Gutenberg text
4. Wikipedia only for broad structural corroboration

## Guardrails applied

- No pirate mirrors or unauthorized reposts
- No chapter claim without support in the frozen bundle
- No exact quotation unless it appears in the frozen Long text
- No later commentary imported as if it were original chapter content

## Risk notes

- The source is rich enough for direct chapter work because the full twelve-book text is available.
- Translation wording can vary across editions, so reader-facing prose should stay paraphrase-first unless a short exact line is clearly anchored.
- Book headings are numeric rather than descriptive; chapter specificity must come from chapter-local motifs, examples, and tensions rather than modern subtitle invention.
