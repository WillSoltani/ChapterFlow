# Quality Memory

- Generic Stoicism is a fail. Each book must feel unmistakably like that book.
- Hard depth cannot be medium with extra words.
- Do not let support surfaces narrate `the chapter` or drift into sloganized advice.
- Repeated sentence tails, recap replay, review-card echo, and generic implementation plans are auto-fails.
- Use the frozen text as factual authority. Stay paraphrase-first unless a short exact line is directly supported.
- Keep examples modern and concrete, but tie each one to the book's actual mechanism rather than generic calmness.
- If prose weakens, reroute through local patch or repair before conversion.
