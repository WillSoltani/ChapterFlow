# Style Memory

- Write like an authored explainer, not a summary machine.
- Start from pressure, event, or a live customer struggle instead of a thesis announcement.
- Keep paragraphs on distinct jobs: anchor, mechanism, tension, limit, implication, bridge.
- Stay concrete and chapter-specific; if a sentence could fit another innovation book, cut it.
- Easy opens a door, medium explains causal demand and application, hard keeps a threshold question or limit alive.
- Competitive tone stays severe and credible, never sloganized.
- No em dashes, no fake science, no generic coaching, no contamination phrases, and no stock innovation jargon.
