# Quality Memory

- Chapter gate passes only when the full artifact chain exists and the prose clears critic and lint.
- Auto-fails include invented facts, generic prose, thesis-first openings, hard-medium collapse, repeated endings, contamination leakage, empty quizzes, and plain-string scenario fields.
- Support surfaces must do different jobs: takeaways compress, moreDetails deepen, review cards retrieve, recaps retrieve/connect/predict, and implementation plans stay chapter-specific.
- Review package must wrap the full validated chapter JSON, not a partial chapter object.
- Seal continuity hashes only after validation passes and the on-disk artifact check is clean.
