# Source Discovery

## Goal
Freeze a lawful, chapter-usable bundle for `The First 20 Hours` before any chapter work.

## Discovery outcome
- No public-domain full text exists.
- The official book site provides the cleanest chapter map and chapter blurbs.
- Google Books provides the strongest bibliographic record for the 2013 Portfolio edition family.
- Penguin Random House confirms the mainstream paperback metadata.
- Secondary support exists for the book's thesis and rapid-skill-acquisition framing, but not for unrestricted chapter-by-chapter full text.

## Edition decision
Auto-lock the dominant English Portfolio edition family.

Why no user question was needed:
- no translation ambiguity was found
- no competing chapter order was found
- the 2013 and 2014 English-market records appear chapter-compatible for chapterflow purposes

## Frozen source ladder used
1. Official site TOC and chapter blurbs: `https://first20hours.com/`
2. Google Books bibliographic record: `https://books.google.com/books/about/The_First_20_Hours.html?id=Zj99vgEACAAJ`
3. Publisher metadata: `https://www.penguinrandomhouse.com/books/312040/the-first-20-hours-by-josh-kaufman/`
4. Author-led / excerpt-style secondary framing: `https://www.porchlightbooks.com/blogs/changethis/the-first-20-hours-secrets-of-rapid-skill-acquisition`
5. Public talk summary for high-level concept reinforcement: `https://podwise.ai/dashboard/episodes/5376308`

## Constraint carried forward
This freeze supports confident chapter mapping and narrow paraphrase. It does not support broad exact quotation outside officially visible text.
