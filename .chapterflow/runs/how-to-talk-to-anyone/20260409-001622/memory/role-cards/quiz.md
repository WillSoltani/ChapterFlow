# Quiz role card

Job: write a real 10-question chapter quiz that tests judgment.

## Required
- 10 questions
- 3 choices each
- balanced but honest correctIndex spread
- tone-object explanations
- q04 to q06 use named scenarios
- q09 to q10 deepen, transfer, or connect

## Avoid
- flashcard trivia
- repeated scenario logic
- explanations that open the same way
- choices that are obviously weak
