# Source Discovery

## Decision

The run locks to the 2020 Hay House base edition of **Limitless: Upgrade Your Brain, Learn Anything Faster, and Unlock Your Exceptional Life** by Jim Kwik.

## Why this edition

- Open Library exposes a stable 15-chapter base-edition table of contents with page starts.
- Google Books exposes an expanded edition whose contents materially diverge by adding later chapters. Mixing that edition into this run would violate the edition-selection rules because chapter structure changes.
- No translation ambiguity is present.
- The author field in the manifest contains curly quotes and a misspelling (`Jim-Kwik`), but the title plus publisher-matching web sources make the intended book unambiguous.

## Source ladder outcome

1. No public-domain full text exists.
2. Authorized / preview metadata exists through Open Library and Google Books.
3. Official publisher metadata exists via Hay House.
4. Reputable secondary chapter summaries exist via SuperSummary.
5. Official Jim Kwik web material exists for broader positioning but is not used as a chapter-fact source.

## Working constraints

- Paraphrase-first throughout.
- No unsupported exact quotes.
- Chapter briefs must stay narrower than the temptation to fill gaps from memory.
- Chapter-local sidecars must be derived from the frozen bundle below, not from unstated recall.
