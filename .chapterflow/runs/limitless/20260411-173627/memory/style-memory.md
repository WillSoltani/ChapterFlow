# Style Memory

- Teach directly. Avoid narrating the chapter.
- Start from pressure, event, tension, or a live problem, not thesis-first summary.
- Specific beats generic. Concrete beats abstract.
- Keep paragraph jobs distinct: anchor, mechanism, tension, limit, implication, bridge.
- Medium must deepen mechanism and application. Hard must add boundary, contradiction, cost, failure mode, or synthesis.
- Competitive tone must be credible and concise, not poster-ready.
- No made-up science, invented anecdotes, or generic self-help filler.
- No em dashes.
- Reinforcement surfaces must do different jobs rather than replay the same sentence.
