# Quality Memory

- No chapter can skip pre-writer artifacts, writer, editor, critic, prose decision, converter, quiz, validator.
- No validated artifact before the full chain exists.
- Critic target is at least 10/12 with no auto-fails.
- Prose audit auto-fails on duplicate sentences, ending echoes, paragraph-role repeats, hard/medium collapse, contamination, generic prompts, or generic implementation language.
- Review package must wrap the full validated chapter payload, not a partial object.
- Source sidecars must exist before writing and must derive from frozen sources.
- Release later assembles from `validated/*.chapter.json` only.
