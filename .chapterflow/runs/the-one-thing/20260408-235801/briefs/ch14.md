Chapter 14 should argue that purpose has to be translated into priority, so larger direction starts governing actual choices. The chapter should turn broad purpose into ranked focus rather than leaving it abstract.

What Makes This Chapter Distinct:
This chapter should feel like the operational follow-through to purpose. It should not replay the argument for purpose itself; it should show that purpose only becomes useful when it starts selecting what comes first.
