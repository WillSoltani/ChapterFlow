Core Claim:
Chapter 4 argues that treating all tasks, goals, or obligations as peers is a productive lie. Some actions carry more leverage than others, so equal weighting does not create fairness or responsibility. It creates dilution.

What Makes This Chapter Distinct:
This chapter is strongest when it attacks task democracy directly. It should feel like the point where the book stops tolerating flat priority lists and starts forcing hard ranking.

Author Logic Chain:
First the author names equal weighting as a lie rather than as a harmless habit.
Then the author argues that different actions produce different downstream effects, so ranking is unavoidable.
Then the author makes the practical demand: stop treating every claim on attention as equal and put prime effort where consequence is highest.

Required Anchors:
- everything matters equally as a false belief
- unequal leverage means ranking is necessary
- equal weighting produces dilution rather than fairness

Frameworks or Terms Introduced:
- equal-weighting lie: the belief that every task should receive similar attention
- forced ranking: sorting claims by consequence instead of by guilt or visibility
- dilution: the loss of force that follows when prime attention is spread too evenly

Specific Applications:
- ranking one project decision above several respectable maintenance tasks
- choosing the concept that changes an exam score instead of reviewing every page evenly
- deciding which personal obligation actually stabilizes the week instead of giving each concern symbolic attention

Common Misreadings:
- reducing the chapter to a generic 80/20 slogan
- using ranking language as permission to neglect real responsibilities
- pretending that visible urgency automatically equals importance

Counterarguments or Limits:
Sharp ranking is necessary, but the chapter should not erase real maintenance work, duty, or care. The point is unequal consequence, not permission to ignore everything inconvenient.
