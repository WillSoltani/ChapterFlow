# Style Memory

- Write like a sharp human explainer: concrete, selective, readable, and unmistakably authored.
- Open on friction, contrast, or a live dilemma instead of thesis-first abstraction.
- Keep each chapter tied to its specific mechanism inside `The One Thing`, not to generic productivity advice.
- Easy should be genuinely simpler, medium should explain mechanism and application, and hard should keep a real threshold, limit, or tension alive.
- Tone differences must do different jobs: gentle lowers resistance, direct clarifies the mechanism, competitive sharpens stakes and leverage.
- Avoid breezy self-help filler, corporate polish, pseudo-science, contamination phrases, and repeated sentence skeletons.
