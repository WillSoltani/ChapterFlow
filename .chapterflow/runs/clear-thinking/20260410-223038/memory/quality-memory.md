# Quality Memory

- No chapter skips the chain: brief -> outline -> quiz blueprint -> source sidecar -> canonical draft -> edited draft -> critic -> prose decision -> converter -> quiz -> validator.
- Critic gate before structure. Never convert weak prose just because the schema is waiting.
- Auto-fail on invented facts, contamination phrases, repeated paragraph jobs, repeated endings, tone collapse, empty quiz in generate mode, or scenario strings in flagship mode.
- Hard depth must add new structure, not expanded medium.
- Review package must wrap the full validated chapter JSON, not a partial object.
- Seal chapter hashes only after chapter lint, review-package lint, and artifact guard all pass.
- Release assembly may read only `validated/chNN.chapter.json` files.
