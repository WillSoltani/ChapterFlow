# Style Memory

- Teach directly. Do not narrate the existence of the chapter when a sentence can simply teach the idea.
- Open from pressure, event, or a live question, not a thesis announcement.
- Prefer specific, concrete prose over abstract summary language.
- Keep paragraphs on distinct jobs: anchor, mechanism, tension, limit, implication, or bridge.
- Easy must be genuinely easier, not thin medium. Medium explains mechanism plus application. Hard adds boundary, contradiction, cost, or synthesis.
- Competitive tone must be sharp and credible, never poster-ready.
- Avoid fake precision, filler neuroscience, generic self-help uplift, and reusable coaching language.
- Reinforcement surfaces must each do different work: key takeaway, cards, recap, prompts, and implementation plan cannot echo each other.
