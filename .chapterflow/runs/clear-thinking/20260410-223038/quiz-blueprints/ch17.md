Quiz Blueprint — Chapter 17

Core checks:
- define problem framing, obstacle, responsibility, and root cause operationally
- distinguish symptom from actual problem
- preserve the role of ownership without blame theater
- reject solution search before the problem is framed
- keep the bridge into exploring possible solutions

Difficulty split:
- 3 easy recall / understanding questions
- 4 medium apply / analyze questions
- 3 hard analyze / evaluate questions

Question targets:
1. definition of problem framing
2. why symptoms mislead
3. what responsibility means here
4. work scenario about visible complaint versus real obstacle
5. dialogue about blame versus ownership
6. school scenario about defining the bottleneck before solving
7. root cause
8. why overanalysis is a risk
9. how framing changes later decisions
10. threshold test: what must be defined before solution search

Choice-shape rules:
- 3 choices per question
- only one answer should preserve the chapter's actual mechanism
- wrong answers should fail by blaming, oversimplifying causation, or jumping to solutions too early

Explanation requirements:
- easy explanations should restate framing, obstacle, ownership, or root cause plainly
- medium explanations should tie a scenario back to clearer problem definition
- hard explanations should preserve the clarity-versus-overanalysis tension
