Quiz Blueprint — Chapter 16

Core checks:
- define repair, reflection, learning loop, and recovery operationally
- distinguish reflection from rumination
- preserve the order from repair to lesson to resumed action
- reject excuse-making and self-punitive collapse
- keep the bridge into clearer problem definition

Difficulty split:
- 3 easy recall / understanding questions
- 4 medium apply / analyze questions
- 3 hard analyze / evaluate questions

Question targets:
1. definition of repair
2. why mistakes still matter after safeguards
3. what reflection should do
4. work scenario about repairing before explaining
5. dialogue about accountability versus spiraling
6. school scenario about extracting a lesson from a miss
7. learning loop
8. why recovery is not the same as regret
9. how mistakes become useful without becoming excused
10. threshold test: what disciplined recovery requires

Choice-shape rules:
- 3 choices per question
- only one answer should preserve the chapter's actual mechanism
- wrong answers should fail by excusing the mistake, glorifying guilt, or drifting into vague resilience talk

Explanation requirements:
- easy explanations should restate repair, reflection, learning loop, or recovery plainly
- medium explanations should tie a scenario back to sequence, lesson, and changed action
- hard explanations should preserve the accountability-without-collapse tension
