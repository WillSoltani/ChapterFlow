# Style Memory

- Write like a sharp human explainer with taste.
- Specific beats generic. Concrete beats abstract. Insight beats padding.
- No em dashes. No filler neuroscience. No pseudo-precision. No invented authority signals.
- Open on a live tension, scene, or curiosity trigger, not a thesis announcement.
- Every paragraph needs a distinct job.
- Easy must be readable and concrete. Medium explains mechanism. Hard keeps a real limit or threshold question alive.
- Reader-facing prose should not talk about "the chapter" unless unavoidable.
- If support is thin, stay narrow instead of sounding smarter than the brief.
