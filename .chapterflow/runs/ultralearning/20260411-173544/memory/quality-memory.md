# Quality Memory

- No chapter skips brief -> outline -> quiz blueprint -> source sidecar -> canonical -> edited -> critic -> prose audit -> structured -> quiz -> validator.
- No invented facts, quotes, studies, or mechanisms.
- No identical tone objects or plain-string scenarios in flagship mode.
- No recap, card, prompt, or takeaway should echo another surface.
- Hard depth must not be medium made longer.
- Review wrapper must contain the full validated chapter payload, not a partial copy.
- Seal chapter hashes only after validation passes and the artifact bundle is complete on disk.
