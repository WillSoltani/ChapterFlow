# Style Memory

- Write like a sharp human explainer with concrete pressure, not generic self-help polish.
- Open from scene, tension, or live question, never thesis-first.
- Keep every paragraph on one main job and cut repeat landings.
- Stay paraphrase-first and source-bound.
- Avoid fake neuroscience, slogan tails, corporate filler, and chapter-narration language.
- Easy clarifies one clean model.
- Medium explains mechanism plus application.
- Hard must add a real limit, failure mode, or threshold question.
- Tone differences must be functional: gentle lowers resistance, direct clarifies, competitive sharpens stakes without sounding theatrical.
