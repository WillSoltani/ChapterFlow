# Chapter 12 Outline

Chapter Promise:
Default methods can feel safe and natural even after they stop producing the best results. Experimentation matters because the learner may need to step outside comfort-zone habits to find a better approach.

Core Arc:
1. Familiar methods can become invisible because they feel normal.
2. Experimentation tests alternatives instead of assuming the default is best.
3. Useful discomfort can reveal hidden assumptions, better fit, or stronger results.
4. The principle still needs a limit: experimentation should connect to the real skill, not random novelty.
5. Bridge toward launching a first ultralearning project with a wider toolkit.

Required Beats:
- Name the principle narrowly: experimentation pushes beyond default methods and comfort-zone habits.
- Explain why defaults can survive without being questioned.
- Show that alternatives can reveal what the default was hiding.
- Keep experimentation practical rather than reckless.
- End by looking forward to using the principles in project form.

Scenario Map:
- work / decision_point: test an alternative workflow instead of repeating the default routine
- school / dialogue: familiar study method fails under discussion, prompting a different approach
- personal / dilemma: choose between safe repetition and testing a different practice method
- work / reset_moment: plateau reveals the default method is no longer enough
- school / planning_choice: plan a study week that includes deliberate testing of alternatives
- personal / mistake_recovery: recover from mistaking experimentation for randomness by reconnecting tests to the skill
