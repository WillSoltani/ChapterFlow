# Chapter 13 Outline

Chapter Promise:
A first ultralearning project is where the book's principles become concrete. The project has to matter, compete for time, and have enough direction to be more than dabbling.

Core Arc:
1. Shift from understanding the principles to using them in a real project.
2. Define ultralearning projects as serious, committed, and concretely directed.
3. Show why protected time and project seriousness matter.
4. Keep the chapter realistic: serious is not the same as vague grandiosity.
5. Bridge toward the final reflection on unconventional education.

Required Beats:
- use the frozen project-design support from the Scott Young series
- preserve the anti-dabbling claim
- tie seriousness to commitment, protected time, and concrete direction
- keep the first project practical enough to start
- end by widening back out toward unconventional education

Scenario Map:
- work / decision_point: choose a real project instead of endless preparation
- school / dialogue: clarify that a project needs direction and time, not just interest
- personal / dilemma: choose between a meaningful project and a comfortable half-commitment
- work / reset_moment: realize vague ambition is not the same as an ultralearning project
- school / planning_choice: protect time and define project scope
- personal / mistake_recovery: repair a project plan that was too vague to be actionable
