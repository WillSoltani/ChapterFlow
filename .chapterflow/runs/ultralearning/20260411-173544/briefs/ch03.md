Core Claim:
Becoming an ultralearner starts with project design, not adrenaline. Scott Young frames the move in practical terms: choose one target, pick a workable format, prepare before the full push, and avoid goals so vague or inflated that they collapse on contact. The chapter matters because it turns ultralearning from an inspiring idea into a buildable approach. Its deeper claim is that intensity only works when it is attached to a project shape the learner can actually carry.

What Makes This Chapter Distinct:
This is not yet one of the nine principles. It is a setup chapter about project selection, format choice, preparation, and pilot testing. If it loses the one-thing focus, the project-format choices, or the preparation-before-launch logic, it becomes generic planning advice.

Author Logic Chain:
First the author explains that a first ultralearning project should target one thing rather than a pile of ambitions.
Then the author lays out project formats and time structures that fit different lives.
Then the author argues for preparation, resource gathering, and pilot testing before the full learning sprint begins.

Required Anchors:
- pick one thing: specificity matters because broad goals become mushy projects
- project formats: full-time, fixed-schedule, and fixed-hour structures each change feasibility and speed
- preparation and pilot week: serious projects need research, materials, a basic attack plan, and a test run before launch
