Core Claim:
Metalearning means researching why, what, and how to learn before and during a project. Scott Young uses this first principle to slow the learner down just enough to draw a map before sprinting. The chapter matters because intensity without orientation wastes effort, but overresearch can become its own delay. A useful map clarifies purpose, identifies what the skill contains, and points toward methods that match the target.

What Makes This Chapter Distinct:
This is the first principle chapter, and it has to convert project setup into a learning map. If it loses the why-what-how triad, the map metaphor, or the before-and-during research logic, it collapses into generic "do your research" advice.

Author Logic Chain:
First the author argues that serious learners should study the learning problem before charging ahead.
Then the author splits metalearning into why, what, and how so the project has orientation.
Then the author keeps the principle bounded by treating research as a guide for action rather than a replacement for action.
