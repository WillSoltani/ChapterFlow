# Chapter 12 Quiz Blueprint

Core Concepts:
- experimentation means pushing beyond default methods and comfort-zone habits
- default methods can feel safe without being best
- trying alternatives can expose better fit or hidden assumptions
- experimentation should stay tied to the real skill rather than random novelty
- useful discomfort can widen options after understanding has deepened

Question Targets:
1. Define experimentation in the chapter's narrow sense.
2. Explain why default methods can survive without being tested.
3. Apply the principle to a learner stuck in a familiar routine.
4. Distinguish useful experimentation from random novelty.
5. Connect experimentation to the next stage of applying the book's principles.
