# Style Memory

- Write like an authored explainer, not a summary robot.
- Start from pressure, event, or tension instead of a thesis announcement.
- Keep paragraphs on distinct jobs: anchor, mechanism, tension, limit, implication, bridge.
- Stay concrete and chapter-specific; if a sentence could fit another chapter, cut it.
- Easy must open a door, medium must explain mechanism, hard must keep a live threshold question.
- Competitive tone stays severe and credible, never poster-ready.
- No em dashes, no fake neuroscience, no generic coaching, no contamination phrases.
