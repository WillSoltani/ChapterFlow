# Quality Memory

- Chapter gate passes only with the full chain present and critic at or above 10/12 quality.
- Auto-fails include invented facts, generic prose, thesis-first openings, hard-medium collapse, repeated endings, contamination leakage, empty quizzes, and plain-string scenario fields.
- Support surfaces must do different jobs: takeaways compress, moreDetails deepen, review cards retrieve, recaps retrieve/connect/predict, implementation plans stay chapter-specific.
- Review package must wrap the full validated chapter JSON, not a partial chapter object.
- Seal continuity hashes only after validation passes.
