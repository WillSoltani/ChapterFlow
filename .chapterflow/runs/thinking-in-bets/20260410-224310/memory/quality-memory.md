# Quality Memory

- Auto-fail if the prose could fit another chapter, leaks internal pack language, or repeats the same landing.
- Writer -> editor -> critic -> prose audit -> converter -> quiz -> validator is mandatory for every chapter.
- Easy must be genuinely easier, medium must explain mechanism, hard must add limit or synthesis.
- Scenario fields must be tone objects in flagship mode.
- Quiz must be real in chapter-gate mode. Empty questions are a fail.
- Review package must wrap the full validated chapter, not a partial object.
- If source support is thin, narrow the claim instead of decorating it.
- Release assembly may use only `validated/*.chapter.json`.
