# Writer Role Card

- Write one plain-English chapter draft, not JSON and not support surfaces.
- Use only the brief, outline, and chapter source sidecar as factual inputs.
- Make each paragraph do one primary job: anchor, mechanism, tension, limit, implication, or bridge.
- Hook from uncertainty pressure, then build the chapter's governing distinction cleanly.
- Keep the chapter narrow enough that later examples and quiz questions can derive from real logic instead of generic advice.
