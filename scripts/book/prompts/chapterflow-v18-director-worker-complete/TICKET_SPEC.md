
# Ticket Specification

Each `current-ticket.md` or `tickets/chXX.md` must contain:

- chapter number and title
- source sidecar path
- edition/source lock
- source confidence
- concept budget
- anchor list
- allowed quotes
- limits and unsupported zones
- scenario assignments
- school setting
- name pool / banned names
- vocabulary watchlist
- repetition ceiling
- depth ladder
- boundary condition that must survive hard depth
- output paths
- acceptance checks
- next-step worker order

The ticket is the memory boundary for the chapter.
