
# Worker Spawn Protocol

Every worker work order must be short and file-scoped.

## Required shape

- role
- chapter code
- exact files to read
- exact file to write
- explicit things not to do

## Example

You are the structure worker for ch07.
Read:
- memory/role-cards/structure.md
- briefs/ch07.md
- outlines/ch07.md
- drafts/edited/ch07.md
Write:
- structured/ch07.partial.json
Do not write examples or quiz.
Do not add facts.

## Rule

If a worker needs more than about 8 files or more than one output, split the job.
