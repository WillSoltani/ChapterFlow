
# Learning Loop

Prime -> Read -> Apply -> Test -> Practice -> Review

Minimum translation into content:
- Prime: prediction or activating prompt where supported
- Read: 3 to 5 core concepts, not an inflated list
- Apply: 6 scenarios with distinct lesson targets in flagship mode
- Test: 10 questions with 3 choices each
- Practice: 3 if-then plans + 24-hour challenge + weekly practice
- Review: 5 review cards with 2/2/1 difficulty split
