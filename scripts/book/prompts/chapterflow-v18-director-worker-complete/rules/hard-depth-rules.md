
# Hard Depth Rules

Hard depth must add a new layer, not just more pressure.

Required:
- one real boundary condition, failure mode, contradiction, or unresolved tension
- one takeaway or moreDetails that would make no sense at easy or medium
- one self-check prompt that tests the limit, not the main rule

Hard fails if:
- it repeats medium claims with denser language
- it uses harder words without a harder idea
- it adds drama instead of judgment
