
# Wave Protocol

Default width: 6 chapters.

## Rules

- Never mix stages within a chapter once a later stage has started.
- Every chapter in a wave must have brief + outline + quiz blueprint before any writer starts.
- Critic must clear prose before structure starts.
- Structure, scenario, and quiz can run in parallel after edited draft is locked.
- Assembler runs only after structure, scenarios, and quiz all exist.
- Validator runs only on the assembled chapter.
- Patch runs only on failing local sections.
- A chapter is committed only when artifact guard passes.

## Premium routing

The Director may downshift single chapters or pairs for:
- morally dense chapters
- source-thin chapters that require tighter editing
- chapters that fail the calibration floor
