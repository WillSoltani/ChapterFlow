# Learning Loop

The product-level learning loop is:

1. Prime
2. Read
3. Apply
4. Test
5. Practice
6. Review

This pack must preserve that sequence internally even when the public package shape is larger.

## Prime
- start each chapter with 2 to 3 prediction or pretest ideas in the quiz blueprint
- use those to shape openings and q01-q02
- do not turn priming into trivia

## Read
- internal concept budget should usually stay in the 3-5 range
- if the public package has more than 5 takeaways, the extra surfaces must still derive from the same core concepts without pretending the chapter contains more distinct ideas than it does

## Apply
- scenarios must teach distinct applications
- examples must be vivid, named, and concrete

## Test
- 3-choice quiz
- explanations teach mechanism, not just correctness
- use scenario-based prompts where possible

## Practice
- implementation plans must be specific if-then actions tied to the chapter's actual principle

## Review
- review cards should reinforce distinct concepts, not five versions of one point
