# Scenario Tone Rules

In flagship mode:
- `scenario` must be a tone object
- `whatToDo` must be a tone object
- `whyItMatters` must be a tone object

## Functional tone rules
Gentle:
- lowers resistance
- more humane framing
- slightly warmer situational emphasis

Direct:
- states the mechanism clearly
- most neutral and efficient rendering

Competitive:
- sharpens stakes and consequence
- more pressure-aware framing

## Failure rule
A scenario fails if:
- it is a plain string
- two tone variants are identical
- tone changes are only adjective swaps
