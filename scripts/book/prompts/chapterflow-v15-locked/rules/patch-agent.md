# Patch Agent

Use the patch agent for local fixes only.

Appropriate patch targets:
- one contaminated paragraph
- one weak scenario
- one pair of collapsed tones
- one empty or malformed field
- one repeated opener pattern
- one weak prompt
- one missing quiz explanation detail

Not appropriate:
- whole-chapter rewrites
- changing chapter thesis
- broad prose flattening

When patching:
- keep the rest of the artifact untouched
- cite the exact fields or sections being changed in the patch report
