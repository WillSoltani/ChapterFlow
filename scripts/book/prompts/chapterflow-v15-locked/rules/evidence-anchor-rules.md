# Evidence and Anchor Rules

Every chapter should have at least one load-bearing anchor in medium and hard when the source supports it.

Anchor requirements:
- named person, text, or event
- concrete setting or situation
- what happened
- why it matters for the chapter

If the source is thin:
- use fewer anchors
- make them more precise
- do not import outside anecdotes just to create drama

Anchor failure modes:
- decorative name drops
- vague historical references
- no consequence
- no link back to the chapter's governing mechanism
