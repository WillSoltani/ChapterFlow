# Chapter-gate rules

The chapter gate is an internal quality sentry, not a human pause.

## It must check
- prose quality gate cleared
- structure valid
- quiz present if required
- scenario tone policy satisfied
- reading metrics written
- review package written

## It must not
- ask the user for approval
- stop the run unless a true blocker remains after local patching or repair

## Automatic continuation rule
If Chapter 1 and Chapter 2 both pass chapter gate, they establish the baseline quality floor for the rest of the run.
