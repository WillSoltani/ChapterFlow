# Source sidecar rules

If a book source arrives as one large file, create per-chapter sidecars before writing the chapter dossier.

Required sidecars:
- sidecars/source/chXX.source.txt
- sidecars/source/chXX.source.json

Each source sidecar should include:
- chapter heading
- source slice
- source confidence note
- major names and terms
- quote candidates
- ambiguity note if needed

Reader-facing prose may not paste raw sidecar text unless the quote ledger explicitly allows it.
