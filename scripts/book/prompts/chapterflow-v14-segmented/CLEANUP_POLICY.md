# Cleanup policy

Cleanup is a post-release phase.

## Preconditions
Cleanup may run only after:
- final book JSON is validated
- release guard passes
- integration is complete
- build passes
- final cover is in place

## Remove
- intermediate drafts
- outlines
- quiz blueprints
- scratch notes
- temporary repair scripts
- duplicate derived files
- other nonessential generation artifacts

## Keep
- final book JSON
- final cover asset
- source ledger
- edition lock
- source freeze records
- final validation reports
- release metadata needed for auditability

## Policy summary
Do not delete all generation files.
Remove nonessential intermediate artifacts after successful release.
Retain the minimum audit trail and final deliverables.
