# Source Sufficiency Policy

Web-first source discovery is required.

## Enough source for full fidelity
Proceed only when the source freeze provides chapter-local evidence strong enough to support faithful chapter writing.

Examples:
- public-domain full text
- authorized full text or substantial preview
- lawful chapter-local excerpts plus corroborating chapter summaries from reliable sources

## Not enough source
These are not enough by themselves:
- publisher metadata
- TOC only
- library catalog entries
- isolated excerpt context with no real chapter-local evidence

If source sufficiency fails, write a blocker report and stop.
Do not generate a full book from metadata, chapter titles, or high-level principle summaries.
