# Quickstart

## 1) Install the pack
`scripts/book/prompts/chapterflow-v19-sealed-provenance/`

## 2) Audit the pack
```bash
python3 scripts/book/prompts/chapterflow-v19-sealed-provenance/tools/chapterflow_v19_pack_audit.py   scripts/book/prompts/chapterflow-v19-sealed-provenance
```

## 3) Launch a run
```bash
bash scripts/book/prompts/chapterflow-v19-sealed-provenance/launch.sh   "Extreme Ownership"   "Jocko Willink, Leif Babin"
```

## 4) Paste the generated launch prompt into the Director session
`RUN_ROOT/manifests/launch-prompt.txt`
