# Learning Loop

All chapter surfaces should support this sequence:
1. Prime
2. Read
3. Apply
4. Test
5. Practice
6. Review

Operational defaults:
- 2–3 priming/prediction questions per chapter blueprint
- internal concept budget: 3–5 core ideas per chapter
- 6 examples in flagship mode, each teaching a different application
- 10 quiz questions in flagship mode
- implementation plans must be specific, not generic
- review cards must support later spaced review in the app layer
