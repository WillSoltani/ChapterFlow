# Meta-Distance Rules

Teach the idea, not the chapter.

Banned in learner-facing fields unless absolutely necessary for attribution in breakdowns:
- "the chapter says"
- "this chapter"
- "the chapter's"
- "chapter 1"
- "the author argues"

Allowed sparingly in breakdowns:
- 1 to 3 uses of the author name per depth for source attribution

Forbidden in takeaways, moreDetails, prompts, review cards, keyTakeawayCard, implementation plan, and quiz explanations.

If a sentence can be rewritten to teach directly to the reader, do that.
