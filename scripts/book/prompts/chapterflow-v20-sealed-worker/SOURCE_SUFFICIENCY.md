# Source Sufficiency

For copyrighted books, do not generate a full-fidelity book package from metadata/TOC/excerpt context alone.

Minimum for full fidelity:
- stable edition lock
- chapter map
- chapter-local lawful evidence for each chapter strong enough to support a brief
- enough lawful source text or publisher-authorized excerpts to keep the prose source-bound rather than prior-based

If this floor is not met:
- write `reports/source-blocker.md`
- set state to `blocked`
- stop
