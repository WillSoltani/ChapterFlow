# Commit Protocol

A chapter may be committed only if all are true:
- brief exists
- outline exists
- canonical draft exists
- edited draft exists and differs from canonical
- critic report exists
- structure partial exists
- scenario partial exists
- assembled chapter exists
- quiz exists unless explicitly deferred by manifest
- validation report exists
- validated chapter exists
- all stage receipts exist
- provenance guard passes
- artifact guard passes

Commit writes:
- commits/chXX.commit.json
- continuity updates
