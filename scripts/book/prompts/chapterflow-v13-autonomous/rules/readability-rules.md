Readability rules

Easy:
- open with a pictureable situation in the first 2 sentences
- prefer short and medium sentences
- concrete nouns first
- avoid stacked abstractions
- grade target 8-9
- one clean model, one practical implication, one landing
- no theory stacking
- no second conclusion after the point is made

Medium:
- mechanism plus application
- grade target 10-11
- each paragraph must add a new function
- show why the idea works, where it catches, and how it applies
- no paraphrase padding from easy

Hard:
- keep cognitive load high but readable
- grade target 12
- add tension, limit, synthesis, threshold
- add new value through boundary, contradiction, cost, hidden structure, or synthesis
- do not reuse medium's ending beat
- deeper does not mean longer by default

Preview rules:
- preview must ask or imply a real prediction
- preview must not explain the next chapter fully
- preview must stay short

Recap retrieve rules:
- retrieve sections must be recall challenges, not summaries
- recap text must compress rather than restate
- if the recap sounds like a mini-breakdown, cut it back
