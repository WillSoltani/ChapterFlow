Teach the idea, not the chapter.

Hard rules:
- zero "the chapter says" in takeaways, moreDetails, quiz explanations, scenarios, prompts, cards, and implementation plans
- avoid "Chapter N" in reader-facing content except for rare recap / preview contexts where numbering is structurally required
- use the author name sparingly in breakdowns only
- if a sentence can be rewritten to teach directly, rewrite it

Bad:
- "The chapter teaches..."
- "This chapter warns..."
- "The chapter's lesson is..."

Good:
- state the mechanism directly
- ask the reader a live question
- explain the implication without narrating the source artifact
