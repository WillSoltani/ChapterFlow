Source sidecar rules

For web-discovered or single-text sources:
- create one sidecar per chapter before writing
- keep chapter-local excerpts separate from the broader source bundle
- source sidecars may support the brief
- source sidecars may not be pasted verbatim into the breakdown except via approved quote ledger
- source sidecars must be derived from the frozen source bundle, not from memory

Required:
- `sidecars/source/chXX.source.txt`
- `sidecars/source/chXX.source.json` with title, heading, approx words, proper nouns, repeated terms, and source references
