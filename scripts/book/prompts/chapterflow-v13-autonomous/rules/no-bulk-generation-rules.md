No-bulk-generation rules

Repo scripts may not:
- generate chapter breakdowns
- generate takeaways
- generate moreDetails
- generate examples
- generate quizzes
- generate implementation plans
- generate review cards
- generate recap text
- generate key takeaway cards

Repo scripts may:
- assemble release from validated chapters
- slice sources
- compare hashes
- run validators
- wire repo files
- build and test

Any script that authors reader-facing content is a hard policy violation.
