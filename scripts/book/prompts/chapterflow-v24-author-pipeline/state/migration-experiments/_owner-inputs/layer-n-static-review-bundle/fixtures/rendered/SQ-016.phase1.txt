Title: Two Agenda Runs Scenario: At a March project review in the back office, the facilitator watches a neat agenda end in a quick vote and three weeks of quiet resistance. At the June review, the same table holds Paul C. Nutt's process notes, a bargaining column, and an implementation map. The meeting takes longer. The follow-up takes less. People can see which tradeoffs were made before the work begins. What to do: The facilitator changes the agenda so bargaining happens before the vote and implementation owners are named before anyone leaves the table.
