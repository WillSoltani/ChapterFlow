# QUIZ KEY ADJUDICATION — The Power of Purposeful Practice

## Questions and choices
Q1. A pianist plays a recital piece from start to finish six times and stumbles at the same two-measure turn each run. Which change best shows purposeful practice?
   a) Slow the two-measure turn, record only that passage, and adjust the hand motion before the next attempt.
   b) Slow the two-measure turn, record only that passage, and change fingering before the next attempt.
   c) Switch to a favorite piece for confidence before returning tomorrow.

Q2. Which first move turns vague exam effort into purposeful practice on a repeated redox-reaction error?
   a) Create a redox-only set, check each step, and rewrite the first failing step.
   b) Reread the whole chemistry unit to rebuild surrounding context before drilling.
   c) Take the hardest full practice test and review the score afterward.

Q3. Diagnosis: full-demo practice keeps missing the same security-question slide. What is wrong with the practice?
   a) The trainee needs more total demo hours before the slide can feel natural.
   b) The demo should be rehearsed under more realistic sales pressure.
   c) The whole performance is repeated while one weak point keeps surviving.

Q4. Same swim sets, same plateau, same right-arm crossover on video. Which next session best fits purposeful practice?
   a) Add laps at the same pace and hope consistency returns through volume.
   b) Use a lane-line cue for one length, check video, then repeat before distance.
   c) Take a week off because the plateau mainly shows accumulated fatigue.

Q5. A memory trainee like Steve Faloon expands digit recall only after reviewing where each attempt breaks and changing the grouping strategy. What makes that improvement different from ordinary repetition?
   a) Memory work gives unusually clear scores, so improvement is easier to see.
   b) Each miss redesigns the next attempt, turning recall into feedback.
   c) Digit strings reduce context, so talent matters less than in other skills.

Q6. "Nightly repetition will eventually fix uneven knife cuts." What is wrong with that claim?
   a) Enjoyable repetition may build comfort while leaving size differences untouched.
   b) Uneven cuts can become fluent unless a visible size target guides the next cut.
   c) Harder recipes add challenge but may hide the same knife-control problem.

Q7. Completion: feedback helps a practice loop only when it ___.
   a) adds a harder topic that stretches vocabulary and attention
   b) creates a larger block of time for uninterrupted practice
   c) changes the next attempt while the mistake is still traceable

Q8. A warehouse trainee is learning label placement. Plan A: label fifty boxes and get a score at the end. Plan B: label five boxes, compare each to a template, adjust, then label five more. Which is stronger?
   a) Plan B, because feedback arrives soon enough to alter the next small batch.
   b) Plan A, because more boxes create a realistic workload.
   c) Both are equal if the trainee is paying attention.

Q9. A handling goal says only, "corner better." Which revised target is useful enough to practice?
   a) Ride the same route until cornering starts to feel more natural.
   b) Choose the steepest descent and practice staying brave through the turn.
   c) Hold the outside pedal down and keep the tire inside a chalk line for five turns.

## ANSWER KEY (with explanations)
Q1: b — The two-measure drill isolates the recurring miss and uses recording as feedback. Full runs hide the fault inside stamina, and a favorite piece avoids the weak spot.
Q2: a — The redox-only set turns a broad ambition into a specific goal with immediate feedback. Rereading and hard tests may feel serious while leaving the repeated first-step error untouched.
Q3: c — The repeated security-question failure is the training target. More total hours or pressure can preserve the same weak response unless that slide gets isolated and corrected.
Q4: b — The lane-line cue creates a method change aimed at the visible fault. More identical laps protect the plateau, while rest alone does not test the arm-crossing pattern.
Q5: b — The key is not digits by themselves. The miss changes the next grouping strategy. Measurement helps, but the mechanism is the correction loop, not a claim about talent.
Q6: b — Repetition can preserve the uneven motion. A visible size target gives feedback before the next cut. Harder recipes would add noise before the basic correction is made.
Q7: c — Recording only helps if it is used. Playback can show the exact sound or pause to repair. Harder topics and longer sessions may create more material without correction.
Q8: a — Plan B shortens the loop between attempt and correction. Plan A may be realistic, but end scoring lets the same error repeat fifty times before the method changes.
Q9: c — The chalk mark, outside pedal, and five repeats make the goal visible and correctable. Feeling natural is too vague, and a steep descent adds risk before feedback is clean.
