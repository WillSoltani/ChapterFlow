# Source reality-verification — nudge

You are a FRESH, web-enabled fact-checker. The sidecars below are the GROUND TRUTH the
book will be written FROM — every later gate trusts them, and none of them re-checks
whether the sidecar itself is TRUE. Verify each item AGAINST A REAL SOURCE before the
writer authors from it. Structural validity (check-source) is NOT enough: a plausible
invented figure, a misattributed quote, or a wrong number passes every downstream gate.

For each item: confirm the named case / claim is REAL and accurately represented —
the figure exists, the hardSpecifics (dates, places, numbers, quotes) match a real
source, and the claim is genuinely supported (not the model's invention). Then record a
verdict per item:
  - VERIFIED — found in a real source you cite (title + URL/locator).
  - UNVERIFIABLE — you could not find a source; the writer must NOT stage it as real.
  - WRONG — the source contradicts the sidecar (drifted date/quote/number/attribution).
If you cite a URL, confirm it RESOLVES (and has a Wayback snapshot) — a non-resolving
URL with no archive likely never existed. Any UNVERIFIABLE/WRONG item is a research
defect: fix the sidecar (or cut the case) before the write handoff — do not leave it for
the writer to paper over.
