Owner commission: root-cause why `execution` halted at **77.7 vs bar 80, churn HIGH**
after the S-tier lever set shipped and *worked* (every meter cleared; three blinded
acceptance readers still unanimously called the book "template-stamped"). Fix
permanently, grill the plan until nothing new breaks, implement, test, pin the

## §A Root causes (byte evidence; full record in the acceptance/tiebreak files)

Unifying mechanism, proven three times: **writers execute concrete card instructions
literally and identically. A rule that names ONE shape gets stamped 9×. Only DEALT
instructions produce variety; only NAMED budgets suppress saturation.** The S-tier
levers dealt *staging*; the stamp survived one level down, in shapes the card itself
mandates.

- **RC1 self-inflicted single-shape rules:** rule 3's "exact object to touch" →
  "touch X and say Y" theater (6+ chapters, 11 complaints); PREMIUM LIMITS → the
  identical "Do the opposite when…" closer 9/9 fullReads; one aphorism mold 27/27
  memorable lines.
- **RC2 quiz key/distractor generative asymmetry:** key = the chapter's answer
  (signature vocab, max specificity); distractors = one wrongness monoculture
  (wait/hide/assume/delay after P3b banned polish/optics). All 5 flip-tiebreaks led
  with a quiz-tell must-fix; ~50% of 81 questions keyword-guessable; stem opener
  mold 26/81; **preflight tellRate = 78% of all failures — the 22% first-pass rate
  and quizzes-72 are the same defect.** Questions also march 1:1 in packet-fact
  order (grill-2 #6).
- **RC3 example beat monoculture:** 54/54 examples share demand→behavior→return;
  most re-run the full person/proof/return liturgy (density 70 = repetition
  padding). Practice slots compound it: all four surfaces share one dealt shape →
  "read aloud" chant ×4/chapter (grill-2 #9).
- **RC4 no intra-chapter protagonist thread** (ch05/06/08/09 rotate leads between
  sections) **and the invented-proxy-cast device is universal 9/9** — the stamp the
  readers list FIRST (grill-2 #10). Composite-vs-historical blur flagged 2×.
- **RC5 content-gen effort unpinned ambient config:** writers spawn with no model /
  effort / timeout (today's ambient: gpt-5.5 @ xhigh); reviewers pinned high; effort
  type tops out at "high"; 30-min default timeout. **Honesty (grill-2 #5): the
  halted run very likely ALREADY ran xhigh (same-day config) — the pin buys
  provenance, reproducibility, and timeout headroom; NO content gain is booked to
  it.**
- **RC6 real-case anchors label-thin; jargon unglossed** (14 complaints / 7
  chapters; beginner 78, insight 74).
- **RC7 voice unspecified:** 65% of cadence tics are predictable scaffolding;
  rhetorical questions ≈ absent; ch08 monotone. Tone 70.
- **RC8 practice timer gimmicks** (19-minute challenge; 12-vs-10 discrepancy).

NOT root causes (do not touch): the fixed section schema; the app's labeled
example blocks (**verified live UI: ExamplesList.tsx renders "What To Do"/"Why It
Matters" labels — the review renderer is faithful; de-labeling it would be
instrument-dishonest and is REJECTED**); the framework spine as subject matter;
reviewer harshness (never recalibrate the instrument to pass a book).

## §B Fix set (final)

**Design principles (both grill-derived):**
1. The 9×-literal test: any rule whose nine literal executions look identical must
   be dealt or banded, never fixed-shape.
2. The deal-detector invariant (from BR7 precedent): a detector may never flag what
   the deal itself can mint; thresholds are measured against the deal's worst case
   BEFORE an enforcement tier is promised.

### P-lane — prevention. All deals live in the BRIEF; the card carries them ONCE
(§B0). Universal card prose net-SHRINKS.

- **B0 card single-render fix (grill-1 #1, prerequisite):** `buildAuthorCard` stops
  double-carrying VARIETY — the embedded brief md is stripped of its VARIETY section
  when the machine brief renders the explicit block. Card size re-pinned by a test
  that builds a REAL-shaped v3 brief (not the small fixture); ceiling stays 25k with
  measured margin; brief-md cap test raised to the measured v3 size (documented
  rebase).
- **P10 example ARC deals:** per-example dealt rows
  `(entryPoint, outcomeClass, fieldStyle)`; chapter-level dealt `exampleCount ∈
  {4,5,6}`.
  - entryPoint (6-pool): at-the-demand / mid-behavior / at-the-return-moment /
    aftermath-looking-back / outside-observer-arrives / before-anyone-notices.
  - outcomeClass (5-pool): clean-win / failure / partial / averted-late /
    still-open. **failure|partial slots are dealt ONLY to friction-dealt chapters
    (`requireFrictionExample` stays the master flag — ceil(2N/3) of chapters; the
    ×9 ritual stays un-stamped; grill-1 #2 + prior #14 adjudication).**
  - fieldStyle (5-pool, ≥4 distinct per chapter): direct-imperative / cost-first /
    mechanism-first / question-then-answer / shortest-possible — varies the
    whatToDo/whyItMatters rhetoric inside the app's fixed labels (grill-2 #2,
    honest version).
  - Coverage floors are DEALT AND JITTERED per chapter (distinct-entry floor ∈
    {2,3,4}) so the variety PROFILE itself isn't identical across chapters
    (grill-2 #3); all floors guaranteed by dealer construction — the writer never
    counts.
  - **Liturgy compression:** each example dramatizes ONE beat; other beats ≤1
    clause each; at most 2 examples walk the full loop. An example that scenes an
    ownedCase must ENTER it at a different point than the breakdown telling.
    Breakdown tiers still teach the complete loop (retention/transfer protected).
- **P11 lead thread + device-presence deal:** brief deals `leadThread` =
  {kind: invented|real, name}. Invented → cast[0]; real → a packet-attested person
  (only for chapters whose packet carries a scene-able person; ~40–50% of chapters
  real-led, dealt). fastRead + ≥2 examples follow the dealt lead; supporting cast
  stays. Real leads: packet-attested actions only, no invented quotes (existing
  guardrails). Invented people introduced role-before-name in varied wording.
  **De-stamps the readers' #1-listed device instead of hardening it (grill-2 #10).**
- **P12 quiz TRANSFORM recipe** (replaces rule-5 scan text):
  1. Key first, fresh words (rule 2 unchanged).
  2. Each distractor = the key transformed by a dealt failure mode (8-pool:
     wrong-target / wrong-timing / wrong-proof / wrong-scope / half-measure /
     right-move-wrong-trigger / over-correction / borrowed-authority; 4 dealt per
     chapter; distinct modes within a question). One pointer line keeps the
     CHB12-gate families named (polish/announce/slides/optics/morale — the
     deterministic 7% book gate still counts them; grill-1 #17).
  3. Echo symmetry: a chapter-signature word in the key requires ≥2 distractors
     carrying signature words too.
  4. Stem-shape deals (4 of 8-pool: cold-diagnosis / choose-next-move /
     predict-consequence / spot-the-violation / best-explanation-why /
     ordering-priority / transfer-new-domain / failure-postmortem). **Shapes may
     repeat; WORDING may not: no stem's first four words may repeat another
     stem's** (pigeonhole-safe; grill-1 #4). Question ORDER dealt as a permutation
     — kills the 1:1 fact-order march (grill-2 #6).
  5. Wrong-answer teaching: every explanation justifies the key AND names why one
     tempting distractor fails — varied wording, never a fixed stem. (Known
     ceiling, stated honestly: 3-choice format caps difficulty; a 4-choice schema
     change is out of scope and owner-gated.)
- **P13 practice de-theater + PER-SLOT shapes:** rule 3 keeps number/timebox + one
  concrete move, drops "exact object to touch"; **the four practice surfaces
  (tryThisNow / 24h challenge / weekly practice / if-then contexts) get FOUR
  DISTINCT dealt shapes** (extends the existing pool; kills the read-aloud×4 chant;
  grill-2 #9). Timers: round set {5,10,15,20,25,30,45,60}, writer-invented timers
  only (packet-sourced numbers exempt), identical where the same action is
  restated verbatim (grill-1 #15).
- **P14 VOICE block** (replaces TONE bullet):
  1. In deepRead/fullRead, no more than 2 consecutive paragraphs open on an
     abstraction; break runs with a person/scene/object. **Scoped to tier-internal
     paragraphs — hook/fastRead openers stay owned by the dealt openerType
     (grill-1 #3).**
  2. Sentence-length contrast: several times per tier, a ≤6-word sentence lands
     beside a ≥25-word one — banded "at least twice, varied placement", never an
     exact count (grill-1 #14).
  3. 1–3 rhetorical questions per chapter (tic meter verified question-blind).
  4. Physical/sensory anchors are DEALT a density: 2–3 designated example slots
     get one concrete prop; the rest get none (54-props-stamp + "scaffold smell"
     avoided; grill-1/2 #7).
  5. Memorable-line shapes dealt (5-pool: reversal / redefinition / cost-statement
     / pointed-question / imperative; 3 per chapter).
- **P15 limits de-stamp:** `limitsPlacement` dealt (early-aside /
  inside-a-failing-example / closing-paragraph). Requirement unchanged.
- **P16 first-mention grounding, dealt forms:** every real company/event/date gets
  context at first mention drawn from the packet (drop/soften if the packet has
  none — never invent), in one of 3 DEALT grounding forms (appositive /
  prior-sentence setup / parenthetical era+role — no single appositive rhythm ×9;
  grill-1 #14); jargon gets an in-paragraph plain rephrase; hooks may not hang on
  an unanchored date/name.

Prunes paying for the additions: VARIETY double-render (−~2.2k from the card),
rule-1 parentheticals, rule-5 scan protocol → recipe, TONE bullet → P14, PREMIUM
"at least one example ends in failure" clause (dealt now), PRACTICE VERB line
merges into per-slot shapes.
