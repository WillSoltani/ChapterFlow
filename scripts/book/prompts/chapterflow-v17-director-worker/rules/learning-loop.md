# Learning Loop

Every chapter must support this loop:

1. Prime
- prediction or pretest energy
- curiosity before explanation

2. Read
- clear breakdowns
- 3–5 internal concepts, even if the public surface is larger

3. Apply
- six distinct scenarios by default
- each scenario teaches a different application

4. Test
- 10 real questions in flagship mode
- 3 choices
- explanations teach mechanism

5. Practice
- chapter-specific if-then plans
- 24-hour challenge
- weekly practice

6. Review
- 5 review cards by default
- retrieval, not passive recap
