# Scenario Tone Rules

`examples[].scenario`, `whatToDo`, and `whyItMatters` must be tone objects:
- gentle
- direct
- competitive

A plain string is a fail.

Tone differences must be functional:
- gentle = lower resistance, contextualize
- direct = diagnose mechanism
- competitive = sharpen stakes and edge

Scenario setup itself must reflect tone, not only the teaching fields.
