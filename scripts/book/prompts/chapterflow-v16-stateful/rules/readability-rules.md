
# Readability Rules

- Easy should feel easy.
- Medium should explain.
- Hard should deepen.

Guardrails:
- no compressed pseudo-academic phrasing in easy
- no thesis-first opening
- no repeated sentence skeletons
- no duplicated words
- no truncated endings
- no synonym rotation for the chapter's core term unless the substitution is unquestionably clean

If a sentence sounds assembled instead of authored, rewrite or cut it.
