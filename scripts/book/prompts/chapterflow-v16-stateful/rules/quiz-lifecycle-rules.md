
# Quiz Lifecycle Rules

By default, chapter gate includes a real quiz.

Rules:
- quiz questions must be non-empty by chapter validation
- exactly 10 questions in flagship mode
- exactly 3 choices each
- explanation is a tone object
- no two questions test the same principle
- q04 to q06 use named-character situations where supported
- q09 to q10 synthesize or transfer, not just recall
