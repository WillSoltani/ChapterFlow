
# Learning Loop

The learning contract is:

1. Prime
2. Read
3. Apply
4. Test
5. Practice
6. Review

Use the research-backed defaults:
- 2 to 3 priming questions when helpful
- 3 to 5 real concepts per chapter unless the source clearly supports more
- scenario-based transfer
- 3-choice quiz design
- implementation intentions
- review surfaces that can later feed spaced review

Do not bloat the prose to perform the learning loop.
The loop should be visible in the chapter surfaces, not as repetitive explanation about the loop itself.
